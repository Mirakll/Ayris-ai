Голос
Вся речевая цепочка на одной странице: распознавание (STT), синтез (TTS), слово активации и микрофон. Страница прокручивается вертикально.
Распознавание речи (STT)
Режим
Онлайн точнее и без моделей на диске, офлайн — без сети. «Авто» начинает с облака и откатывается на офлайн при потере связи.
Локальный движок
Движок распознавания для офлайн-режима. GigaAM точнее на русском.
Модель
Файл модели в папке моделей. Модели скачиваются в менеджере моделей.
Модель для выбранного движка не скачана.
Облачный провайдер
Сервис распознавания для онлайн-режима.
Адрес сервиса
Полный URL метода транскрипции OpenAI-совместимого API. Пусто — адрес OpenAI по умолчанию. Показывается для провайдера «OpenAI-совместимый».
Модель
Идентификатор модели распознавания у сервиса. Пусто — модель по умолчанию (whisper-1).
Имя записи
Короткое латинское имя записи ключа, например yandex.
Ключ облачного сервиса
Вставьте ключ — он не попадёт в файл настроек. Ключ хранится в диспетчере учётных данных Windows, а не в config.toml.
Облачный движок выбран, но ключ не задан — команды будут молча отклоняться.
Тест распознавания
Проверьте микрофон и движок: запишите короткую фразу и сверьте текст.
Слушаю…
Изменения распознавания применятся после перезапуска воркера.
Синтез речи (TTS)
Движок
Чем озвучивать ответы. Piper — быстрый локальный голос.
Голос
Голос выбранного движка. Свои модели можно загрузить ниже.
Адрес сервиса
Базовый URL OpenAI-совместимого API. Пусто — адрес по умолчанию (OpenRouter). Показывается для движка «OpenAI-совместимый».
Модель
Идентификатор модели синтеза у сервиса — обязателен для облачного голоса.
Имя записи
Имя записи ключа, например openai.
Ключ облачного сервиса
Вставьте ключ — он не попадёт в файл настроек. Ключ хранится в диспетчере учётных данных Windows, а не в config.toml.
Скорость
1.0× — обычный темп речи.

Проба голоса
Произнести тестовую фразу выбранным голосом с текущими скоростью, тоном и громкостью. «Выбрать файл модели…» доступно для Piper (.onnx) и Coqui (.pth).
Запасной облачный голос
Если локальный синтез не справился, озвучить ответ через облако.
Изменения синтеза применятся после перезапуска воркера.
Слово активации (Wake Word)
Активация голосом
Реагировать на «Айрис» и его варианты без нажатия клавиш.
Движок
Чем распознавать слово активации.
Режим микрофона
Всегда слушать, только по клавише или оба способа сразу.
Чем больше вариантов, тем терпимее к произношению; выше чувствительность — чаще ложные срабатывания.
Новый вариант
Например «слушай айрис». Слово активации должно быть не короче двух символов. Enter или кнопка «Добавить».
Пауза после срабатывания
Не срабатывать повторно в течение этого времени.
1500 мс
Сколько ждать начала речи
После активации Айрис ждёт столько, пока вы начнёте говорить. Не услышала — тихо перестаёт слушать. Когда речь началась, фраза уже не обрывается по этому времени.
6 с
Продолжать слушать после ответа
После ответа Айрис остаётся слушать то же окно, чтобы продолжить разговор без повторного «Айрис». Промолчите — слушание тихо закроется.
Режим теста активации
Включите режим и произносите слово: здесь видно каждое срабатывание и уверенность.
Проверка слова активации
Счётчики обновляются, пока вкладка видима.
Срабатываний: 0Ложных: 0
Изменения слова активации применятся после перезапуска воркера.
Аудио вход
Устройство записи
Микрофон для распознавания. «Обновить» перечитывает список после подключения микрофона.
Выбранное устройство сейчас недоступно — подключите его или выберите другое.
Усиление
Программное усиление входного сигнала. 100 % — без изменений.
100 %
Уровень сигнала
Полоса — текущий уровень, вертикальная черта — порог речи. Обновляется, только пока вкладка открыта.
−24 дБ

Ниже порога сигнал считается тишиной. Черта на шкале уровня показывает порог.
50 %
Шумоподавление
RNNoise добавляет небольшую задержку, но заметно чище в шумной комнате.
Калибровка микрофона
Измерит шум комнаты и вашу речь и сразу применит усиление, порог и шумоподавление — их можно поправить ползунками выше.
Изменения аудиовхода применятся после перезапуска воркера.
