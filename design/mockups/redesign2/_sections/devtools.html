Логи / DevTools
Живое окно в работающий Ayris — журнал, таблица пайплайна, Python-консоль и здоровье воркеров. Значения уже замаскированы: секреты сюда не попадают. Без запущенного приложения виджеты показывают пустую форму.
Журнал
Общий уровень
Меняет уровень логирования на лету и сохраняет его — перезапускать Ayris не нужно.
Уровень модуля
Точечное переопределение уровня для одного модуля. «Задать» — применить, «Сбросить» — снять.
Сейчас переопределений по модулям нет.
Автопрокрутка
Держать прокрутку внизу, у самых свежих строк.
Последние события
Формат строки: время · уровень · модуль · [request_id] · сообщение. Цвет — по уровню.
Действия с журналом
Открыть каталог логов в проводнике, скопировать видимые строки или очистить вид.
Экспорт для баг-репорта
Собрать zip-архив с логами (значения замаскированы). Отправьте файл разработчику вручную — Ayris ничего никуда не загружает.
Пайплайн
Проходы
Каждый проход: распознавание → интент → действие → результат, с таймингами. Двойной клик по строке — перейти к её логу.
Фильтр по результату
Показать только проходы с выбранным исходом; «К логу» — открыть выбранный проход в журнале.
Команда текстом
Идёт тем же путём, что голос: опасное действие спросит подтверждение. Up/Down — история, Enter — выполнить.
Сухой прогон
Разобрать команду, но не выполнять её.
Выполнить команду
Прогнать введённую команду через пайплайн или повторить последнюю из истории.
Консоль (REPL)
Консоль выполняет любой код Python в контексте приложения — с полным доступом к настройкам, базе и командам. Ошибка здесь может повредить данные. Автозапуска сохранённых сниппетов нет; каждый ввод пишется в журнал безопасности.
Ввод Python
Enter — выполнить, Shift+Enter — перенос, Up/Down — история, Tab — автодополнение, Esc — прервать. Выполнение идёт в фоновом потоке.
Вывод
Эхо ввода, результат и ошибки. Только чтение.
Управление выводом
Прервать выполняющуюся команду (best-effort) или очистить область вывода.
