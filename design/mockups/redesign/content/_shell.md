# Оболочка и Главная (_shell)
Иконка: сфера / дом
Назначение: Каркас единого окна-дашборда Ayris: безрамочная карта, слева витрина со сферой состояния, справа диалог со строкой ввода; гамбургер выдвигает слой настроек с боковой навигацией, а трей и заставка обслуживают окно снаружи.

## Витрина (левая колонка, ShowcasePanel)
- text · логотип · «AYRIS» [accessible: «Айрис»]
- text · часы · формат «HH:mm», обновляются каждую секунду [accessible: «Текущее время»]
- node-canvas · сфера состояния · WebGL-сфера (фолбэк — QPainter), реагирует на состояние и уровень звука [accessible: «Сфера состояния Айрис»]
- text · подпись · «A Y R I S   A S S I S T A N T»
- button · глиф «⤢» / «⤡» · во весь экран и обратно [tooltip: «Во весь экран (F11)» / «Выйти из полноэкранного режима (F11)»] [accessible: «Полноэкранный режим» / «Выйти из полноэкранного режима»] [действие: toggle_fullscreen, клавиша F11]

## Диалог — верхний бар (правая колонка, DialogView)
- button · «≡» · открыть слой настроек [tooltip: «Настройки»] [accessible: «Открыть настройки»] [действие: toggle_settings]
- button · «{имя профиля}  ▾» · выбор профиля ассистента, дефолт «По умолчанию» [accessible: «Профиль ассистента»] [действие: выпадающее меню профилей]
- text · офлайн-подпись · по умолчанию скрыта; текст «Офлайн» или деталь причины [accessible: «Офлайн-режим»]
- button · «–» · свернуть окно [tooltip: «Свернуть»] [accessible: «Свернуть окно»]
- button · «✕» · закрыть окно (прячет, не выключает) [tooltip: «Закрыть»] [accessible: «Закрыть окно»]

## Диалог — центр (пустое состояние / лог)
- badge · аватар-глиф · мягкий треугольник над строкой статуса [accessible: «Статус ассистента»]
- text · строка статуса · дефолт «Привет, чем помочь?»; по состояниям: «Слушаю…», «Думаю…», «Что-то пошло не так» [accessible: «Статус ассистента»]
- log · лог диалога · строки с префиксом роли «Вы» / «Айрис» / «Ошибка» и меткой времени «HH:mm» [accessible: «Лог диалога»] [контекст-меню: «Копировать строку»]
- meter · панель таймеров · строка активных таймеров с подписью «Отменить»; в главной пустое состояние скрыто (иначе «Нет активных таймеров»)

## Диалог — строка ввода (InputBar)
- button · «</>» · режим команды или кода [tooltip: «Режим команды или кода»] [accessible: «Режим команды или кода»]
- text · поле ввода фразы · плейсхолдер «Чем могу помочь сегодня?» [accessible через плейсхолдер] [действие: Enter отправляет]
- button · глиф микрофона · голосовой ввод [tooltip: «Голосовой ввод»] [accessible: «Голосовой ввод» / «Голосовой ввод, режим: {режим}» / «Микрофон выключен»] [действие: toggle микрофона]
- button · глиф-стрелка вверх · отправить команду [tooltip: «Отправить»] [accessible: «Отправить команду»]

## Слой настроек (SettingsLayer, выдвигается гамбургером)
- text · заголовок слоя · «Настройки»
- button · «✕» · закрыть настройки [tooltip: «Закрыть настройки»] [accessible: «Закрыть настройки»] [действие: close_layer, клавиша Esc]
- search · поле поиска настроек · плейсхолдер «Найти настройку» [навигация: ↑/↓ по подсказкам, Enter — выбор, Esc — скрыть]
- list · боковая навигация разделов (NavSidebar) · разделы: «Общие», «Голос», «Команды», «ИИ / LLM», «Горячие клавиши», «Панель / Сфера», «Профили», «Обновления», «Логи / DevTools», «Приватность» [accessible: «Разделы настроек»]

## Трей (TrayController + TrayMenu)
- badge · иконка трея · волновой знак, цвет по состоянию (зелёный/оранжевый/серый) [tooltip: «Ayris — {состояние}» / «Ayris — микрофон выключен» / «Ayris — проблема: {деталь}»] [действие: двойной клик — показать окно]
- toggle · «Микрофон включён» / «Микрофон выключен» · переключение микрофона
- combo · подменю «Режим» · выбор режима микрофона [опции: «Always Listening», «Push-to-Talk»]
- toggle · «Показывать основной оверлей» · показать/скрыть окно
- button · «Настройки» · открыть окно с настройками
- list · подменю «Профиль» · выбор активного профиля (переключатели по списку профилей)
- button · «Выход» · завершить приложение

## Заставка запуска (SplashScreen)
- node-canvas · сфера · анимируется, состояние «Думаю»
- text · вордмарк · «Айрис»
- text · строка этапа · дефолт «Запуск…», обновляется через set_stage (напр. «Поднимаем воркеры…»)

Primary actions: «≡» (настройки), микрофон, «Отправить» (стрелка вверх), поле ввода «Чем могу помочь сегодня?», кнопка профиля «{имя}  ▾», полноэкранный «⤢», трей «Выход».
Состояния: пустой диалог — аватар + строка статуса «Привет, чем помочь?»; по состояниям ассистента статусы «Слушаю…» / «Думаю…» / «Что-то пошло не так»; офлайн — подпись «Офлайн» под профилем; заставка «Запуск…» при инициализации; лог заполняется при появлении реплик.
Заметки: одно окно, безрамочная скруглённая карта; закрытие лишь прячет окно (реальное завершение — «Выход» в трее). Гамбургер выдвигает слой настроек поверх дашборда (сфера прячется на время слоя); Esc/«✕»/гамбургер убирают слой. Полноэкранный режим спрямляет скругления карты (F11/Esc). Набор и видимость элементов диалога (лог, таймеры, профиль, кнопка настроек, микрофон, поле ввода) и вид сферы управляются живыми настройками раздела «Панель / Сфера». Раздел «Команды» может уйти в иммерсивный режим — боковая навигация и поиск прячутся, пока открыт нодовый редактор. Пустое состояние показывается, когда лог выключен или пуст.
