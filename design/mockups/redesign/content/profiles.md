# Профили (profiles)
Иконка: карточки-профили (несколько персон/наборов)
Назначение: Управление профилями (наборы команд, папок и переменных), экспорт/импорт в архив, резервные копии и папка данных.

## Профили
- text · «Профили» · заголовок секции (role h2)
- text · подпись · «Каждый профиль — свой набор команд, папок и переменных. Все профили живут в одной установке; активный отмечен точкой.»
- list · «Список профилей» · строки профиля: «● <имя>» (точка = активный) + вторая строка «<N команда/команды/команд> · <N папка/папки/папок> · <N переменная/переменные/переменных> · создан <ДД.ММ.ГГГГ>» [действие: двойной клик = сделать активным]
- button · «Создать» · открывает диалог ввода «Новый профиль» / «Имя профиля:»
- button · «Дублировать» · создаёт копию выбранного [активна при выборе]
- button · «Переименовать» · диалог «Переименовать профиль» / «Новое имя:» [активна при выборе]
- button · «Удалить» · с подтверждением и резервной копией [активна при выборе и если профилей > 1]
- button · «Сделать активным» · primary; переключает на выбранный [активна если выбран и не активен]
- badge · статусная строка (_BusyRow) · спиннер + сообщение об успехе/ошибке

## Экспорт и импорт
- text · «Экспорт и импорт» · заголовок секции (role h2)
- text · подпись · «Профиль можно сохранить в архив .zip и перенести на другой компьютер. Секреты — API-ключи и токены — в архив не попадают.»
- button · «Экспортировать профиль…» · открывает диалог экспорта
- button · «Импортировать из архива…» · primary; выбор архива через файловый диалог «Выберите архив профиля»
- badge · статусная строка (_BusyRow) · «Экспортируем…» / «Импортируем…» / результат

## Резервные копии
- text · «Резервные копии» · заголовок секции (role h2)
- text · подпись · «Копии создаются автоматически перед импортом и сбросом, и вручную кнопкой ниже. Хранятся последние <MAX_BACKUPS>; папку можно открыть из раздела «Папка данных».»
- button · «Создать резервную копию» · запускает бэкап на фоне
- badge · статусная строка (_BusyRow) · «Создаём копию…» / результат
- list · «Список резервных копий» (BackupList) · строки-карточки: заголовок «<ДД.ММ.ГГГГ ЧЧ:ММ> — <вручную|перед импортом|перед сбросом>», подпись «Размер: <человекочитаемый>»
- button · «Восстановить» · primary; в каждой строке копии [действие: emit пути → подтверждение]
- button · «Удалить» · в каждой строке копии [действие: emit пути → подтверждение]

## Папка данных
- text · «Папка данных» · заголовок секции (role h2)
- text · подпись · «Здесь хранятся база профилей, модели, настройки и резервные копии. Папку можно перенести на другой диск: данные скопируются, а новая папка вступит в силу после перезапуска.»
- badge · плашка-предупреждение (InlineNotice, warning, без крестика) · «Не храните папку данных в облачных клиентах (Syncthing, Dropbox, OneDrive): они синхронизируют файлы во время записи и могут повредить базу. Для переноса на другой компьютер пользуйтесь экспортом профиля.»
- text · путь (role h2) · «Данные и модели хранятся в:\n<путь root>»
- text · деталь · «Расположение: <source_label>. Свободно на диске: <человекочитаемый размер>.»
- button · «Открыть папку профиля» · открывает папку в проводнике
- button · «Изменить папку…» · primary; выбор папки «Выберите папку для данных Ayris», затем подтверждение переноса
- badge · статусная строка (_BusyRow) · «Коп006ируем данные…» / результат / ошибка

## Диалог: Экспорт профиля
- text · заголовок (role h2) · «Экспорт профиля «<имя>»»
- text · подпись · «Выберите, что войдёт в архив. Его можно перенести на другой компьютер.»
- toggle · «Команды и папки» · чекбокс всегда включён и заблокирован (tooltip «Всегда входит в архив»)
- toggle · «Переменные профиля» · чекбокс всегда включён и заблокирован
- toggle · «Список моделей (манифесты, не сами файлы)» · чекбокс всегда включён и заблокирован
- toggle · «Настройки (без секретов)» · чекбокс, по умолчанию включён
- toggle · «Пользовательские звуки» · чекбокс, по умолчанию включён [пересчитывает размер]
- badge · плашка-предупреждение (InlineNotice, warning) · «API-ключи и токены в архив не попадают — их хранит Windows Credential Manager, а в настройках остаётся только ссылка на них. После импорта на другом компьютере ключи придётся ввести заново.»
- text · оценка размера · «Примерный размер архива: ~<человекочитаемый>»
- text · путь назначения · «Путь не выбран» → «Сохранить в:\n<путь>»
- button · «Обзор…» · файловый диалог «Сохранить профиль»
- button · «Экспортировать» · primary [активна только после выбора пути]
- button · «Отмена»

## Диалог: Импорт профиля
- text · заголовок (role h2) · «Импорт профиля «<имя из манифеста>»»
- text · сводка · описание содержимого архива (preview.describe())
- badge · плашки-предупреждения (InlineNotice, warning) · предупреждения архива; и при нехватке моделей «Не хватает моделей: <имена>. Их можно скачать во вкладке «Обновления».»
- list · «Содержимое архива» · строки: «📁 <папка>», «⚙ <команда>» (+ «  ⚠ уже есть» при конфликте), «= <переменная>», «◇ модель: <имя>»
- toggle · «Импортировать в новый профиль» · радиокнопка, выбрана по умолчанию
- text · «Имя нового профиля:» · поле ввода (QLineEdit), предзаполнено именем из манифеста [активно при выборе «новый профиль»]
- toggle · «Влить в текущий профиль «<активный>»» · радиокнопка
- combo · «При совпадении имени:» · [опции: Переименовать новые, Перезаписать существующие, Пропустить существующие] [активно только при вливании в текущий с конфликтами]
- text · заметка о конфликтах · «Совпадают имена: <имена>.» (если есть конфликты)
- toggle · «Применить настройки из архива» · чекбокс (tooltip «Настройки из архива заменят текущие. Секретов в архиве нет — ключи останутся вашими.»; заблокирован с tooltip «В этом архиве настроек нет», если настроек нет)
- button · «Импортировать» · primary
- button · «Отмена»

## Диалог: Отчёт об импорте
- text · заголовок (role h2) · «Профиль «<имя>» обновлён»
- text · сводка · описание отчёта (report.describe())
- badge · плашка-предупреждение (InlineNotice, warning) · «Не хватает моделей: <имена>. Команды сохранены, но не заработают, пока модели не установлены.» (если есть)
- button · «Открыть менеджер моделей» · только при нехватке моделей и наличии обработчика
- button · «Готово» · primary

Primary actions: «Сделать активным», «Импортировать из архива…», «Изменить папку…» (кнопки primary в секциях); в диалогах — «Экспортировать», «Импортировать», «Готово», «Восстановить».
Состояния:
- загрузка/прогресс: неопределённый спиннер (_BusyRow / BusyIndicator) с текстом «Экспортируем…», «Импортируем…», «Создаём копию…», «Создаём копию и удаляем…», «Восстанавливаем…», «Копируем данные…»
- успех/ошибка: цветные сообщения в статусной строке (например «Профиль «<имя>» создан.», «Импорт завершён.», «Копия восстановлена.», «Копия удалена.», «Не удалось …»)
- пусто (резервные копии): «Резервных копий пока нет.»
- недоступно: плашка error «Профили сейчас недоступны: не удалось открыть базу данных.»
Заметки:
- Диалоги подтверждения (ConfirmDialog, опасные): «Удалить профиль?» («Профиль «<имя>» и все его команды, папки и переменные будут удалены без возможности отмены. Перед удалением будет создана резервная копия.» / «Удалить»); «Переключить профиль?» («В редакторе команд есть несохранённые правки. При переключении профиля они будут потеряны.» / «Переключить») — показывается только если в редакторе есть несохранённые правки; «Восстановить копию?» («Содержимое активного профиля «<имя>» будет заменено данными из копии…» / «Восстановить»); «Удалить копию?» («Файл резервной копии будет удалён без возможности отмены:\n<имя файла>» / «Удалить»); «Перенести папку данных?» (детали переноса + предупреждение об облаке / «Скопировать»); «Перезапустить Ayris?» («Новая папка данных вступит в силу после перезапуска…» / «Перезапустить сейчас»).
- Плашка перезапуска: после переноса папки данных сообщение «Готово. Данные скопированы в:\n<путь>\nПерезапустите Ayris, чтобы перейти на новую папку.» и предложение перезапустить.
- Зависимости показа/активности: кнопки списка профилей активируются по выбору; «Удалить» — только если профилей больше одного (последний защищён); в диалоге импорта поле имени и выбор политики конфликтов зависят от выбранного радио и наличия конфликтов; в диалоге экспорта кнопка «Экспортировать» активна только после выбора пути; чекбокс «Применить настройки» заблокирован, если в архиве нет настроек.
- Экспорт не включает секреты (API-ключи/токены); всегда входят команды/папки, переменные, список моделей.
- Кнопка заголовка «Сбросить секцию» скрыта (секция не владеет ключами конфига).
