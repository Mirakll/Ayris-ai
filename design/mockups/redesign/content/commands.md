# Команды (commands)
Иконка: свиток/дерево команд (библиотека макросов)
Назначение: Библиотека команд профиля со списком, поиском и фильтрами; по «Редактировать» открывается полноэкранный редактор одной команды (обзор, действия-ноды, переменные, звуки, история).

## Экран «Библиотека» — список команд
- search · «Поиск команд» · плейсхолдер поля поиска команд
- combo · «» (фильтр статуса) · [опции: Все, Включённые, Выключенные]
- combo · «» (фильтр тегов) · [опции: Все теги, + теги из библиотеки]
- toggle · «Только с конфликтами» · подпись справа от переключателя, показывает лишь команды с конфликтом триггеров
- tree · дерево команд/папок · строки-карточки с фиолетовой обводкой; выключенные приглушены; предупреждающий значок при конфликте триггеров (тултип со списком конфликтующих команд); папка со шевроном ▸/▾; drag-and-drop перемещения и переупорядочивания; клик по выбранной строке или F2 — переименование на месте
- badge · статус-плашка внизу списка · info/error/success сообщения об операциях (по умолчанию скрыта)

Primary actions: «Редактировать» (неактивна без выбранной команды), «＋ Команда», «＋ Папка», «Импорт…»
Состояния:
- Профиль недоступен: «Библиотека команд недоступна: не удалось открыть профиль. Откройте вкладку позже или перезапустите Ayris.»
- Успех массовых операций: «Готово: включено/выключено команд — N из M.», «Тег «…» добавлен командам: N.», «Удалено команд: N из M.», «Экспортировано в …», «Папка экспортирована в …»
Заметки: контекстное меню строки. Для одной команды: «Редактировать», «Переименовать», «Дублировать», «Выключить»/«Включить», «Экспортировать…», «Удалить». Для мультивыбора: «Включить (N)», «Выключить (N)», «Назначить тег…», «Экспортировать выбранное…», «Удалить (N)». Для папки: «Переименовать», «Экспортировать папку…», «Удалить папку». Вверху меню всегда «Новая команда», «Новая папка». Диалоги подтверждения удаления: «Удалить команду?»/«Удалить команды?» («Команда будет удалена без возможности восстановления.» / «Будут удалены команды: N. Действие необратимо.»), «Удалить папку?» («Папка пуста и будет удалена.» / «Внутри команд: N. Они переедут в корень, а папка будет удалена.»), кнопка подтверждения «Удалить». Создание команды/папки — через input-диалог («Новая команда» / «Имя команды:», «Новая папка» / «Имя папки:», «Назначить тег» / «Тег:»). После создания команды открывается редактор.

## Экран «Редактор» — верхняя панель (topbar)
- button · «← К списку команд» · плоская ссылка-крошка возврата (охраняется проверкой несохранённого)
- text · «/» · разделитель (скрыт без открытой команды)
- text · имя открытой команды · заголовок (скрыт без открытой команды)
- badge · «включена» / «выключена» · плашка состояния команды (скрыта без открытой команды)
- chip-group · «Список» · «Ноды» · сегментированный переключатель режима (виден только на вкладке «Действия»)
- tabs · «Обзор», «Действия», «Переменные», «Звуки», «История» · навигация по секциям редактора (кнопки справа)

Состояния: без открытой команды и при ошибке загрузки показывается плейсхолдер «Выберите команду в дереве слева.» (или текст ошибки).

## Редактор · вкладка «Обзор» — секция «Команда»
- text · «Имя команды» (плейсхолдер) · однострочное имя команды; проверка на месте
- textarea · «Описание команды» (плейсхолдер) · многострочное описание
- chip-group · «Теги» · чипы тегов с автодополнением; поле ввода «Добавить тег…»; чип «<тег>  ✕» с тултипом «Убрать тег»
- toggle · «Команда включена» · «Выключенная команда остаётся в списке, но не срабатывает по триггерам.»
- toggle · «Права администратора» · «Перед запуском команда запросит повышение прав через UAC.» [тултип: «Команда запросит повышение прав (UAC) перед запуском действий, которым нужны права администратора.»]
- number · «Приоритет» · [диапазон: -1000..1000] [тултип: «Чем больше приоритет, тем раньше срабатывает при совпадении.»]
- number · «Кулдаун» · суффикс « мс», шаг 100 [диапазон: 0..3600000] [тултип: «Минимальный промежуток между двумя запусками команды.»]

Состояния: ошибки имени — «Имя команды не может быть пустым.», «В этой папке уже есть команда с таким именем.»

## Редактор · вкладка «Обзор» — секция «Триггеры»
- button · «Добавить триггер:» · подпись перед кнопками добавления
- button · «Фраза» · добавить голосовой триггер
- button · «Клавиша» · добавить триггер-горячую-клавишу
- button · «Событие» · добавить триггер системного события
- button · «Расписание» · добавить триггер по расписанию
- card · «Голосовая фраза» · text «Фраза или регэксп, например: включи {device}» (плейсхолдер); подпись слотов «Слоты: …» / «Слотов нет» / «Именованных групп нет» / «Ошибка регэкспа: …»; toggle «Нечёткое совпадение»; toggle «Регулярное выражение»; slider «Порог нечёткости» [диапазон: 0..100, единица «%»]; number приоритет с префиксом «приоритет » [диапазон: -1000..1000]; button «Удалить»
- card · «Горячая клавиша» · text (только чтение) с плейсхолдером «Комбинация не задана»; button «Записать» (отключена без сервиса захвата); button «Удалить»
- card · «Системное событие» · combo (редактируемый) имя события из списка; button «Удалить»
- card · «Расписание» · combo режима [опции: «По расписанию (cron)», «Один раз»]; text значения с плейсхолдером «минута час день месяц день-недели, например 0 9 * * 1-5» (cron) / «ГГГГ-ММ-ДД ЧЧ:ММ» (один раз); подпись-чтение cron; button «Удалить»

Состояния: конфликт триггера — плашка «Уже используется командой: <имена>».

## Редактор · вкладка «Действия» — палитра блоков (левая панель)
- search · «Поиск блока» · плейсхолдер; фильтрует по названию, описанию и типу
- card · карточки блоков по категориям (заголовок категории капсом) · значок-роль + название + описание; опасный блок помечен «⚠» с тултипом «Опасный блок. <описание>»; недоступный приглушён с тултипом причины или «Действие недоступно в этой сборке.»; клик — выбрать, перетаскивание — вставить

## Редактор · вкладка «Действия» — холст нод (центр) и список
- node-canvas · граф нод команды · поток слева-направо; ноды с портами; провода с чипом задержки «Пауза»; двойной клик по ноде — точка останова; ПКМ по ноде — меню, ПКМ по пустому — меню холста
- list · список действий (режим «Список») · дерево блоков с вложенностью; чекбокс включения на строке; суффиксы «(выкл.)», «(не подключено)», «— <комментарий>»; заголовки веток «[Тогда]», «[Иначе]», «[Тело]», «[При ошибке]»; drag-and-drop; контекстное меню строки

Заметки: меню ноды на холсте — «Переименовать» (F2), «Дублировать» (Ctrl+D), «Выключить»/«Включить», «Удалить» (Delete); диалоги «Переименовать ноду» / «Название:», «Задержка на связи» / «Пауза перед следующим блоком, мс:» [диапазон: 0..3600000, шаг 50]. Меню пустого холста — «Добавить ноду», «Упорядочить», «Показать всё». Контекстное меню списка — «Комментарий…» (диалог «Комментарий блока» / «Комментарий:»), «Дублировать», «Копировать», «Вставить после», «Выключить»/«Включить», «Удалить», «Вставить в конец», «Отменить удаление». Статус переполнения вложенности — «Слишком глубокая вложенность блоков.».

## Редактор · вкладка «Действия» — нижняя капсула-пульт (на холсте нод)
- button · «↶» · «Отменить (Ctrl+Z)» (тултип дополняется описанием шага)
- button · «История ▾» · выпадающее меню последних операций (пункт «Нет операций» когда пусто)
- button · «↷» · «Повторить (Ctrl+Shift+Z)»
- button · «＋» · «Добавить ноду» (открывает палитру)
- button · «🗑» · «Удалить выбранную ноду (Delete)» (отключена без выбора)
- button · «⇄» · «Упорядочить»
- toggle · «▦» · «Привязка к сетке» (кнопка-переключатель)
- button · «⤢» · «Показать всё»
- button · «1:1» · «Масштаб 1:1»
- badge · строка статуса · валидация/сохранение (эллипсис при нехватке места, полный текст в тултипе)
- button · «Тест» · запуск теста (отключена без сервиса тест-раннера)
- button · «Сохранить» · сохранение команды (primary)

Состояния статуса: «Проверка пройдена.», «Ошибок: N, предупреждений: M.», «Предупреждений: N.», «Команда сохранена.», «Тест запущен…», «Сухой прогон. …», «Тест не выполнен: …», «Исправьте имя команды: оно пустое или уже занято.», «Исправьте имя команды перед тестом.», «Восстановлен несохранённый черновик.».
Заметки: в режиме «Список» и на прочих вкладках тот же пульт (история слева, статус · Тест · Сохранить справа) стоит обычной нижней строкой под вкладками, а не капсулой.

## Редактор · вкладка «Действия» — инспектор параметров (правая панель)
- text · «Параметры» / «Параметры — <название блока>» · заголовок панели
- text · «Выберите ноду, чтобы изменить её параметры.» · пустое состояние (нет выбора)
- text · «У блока нет параметров.» · пустое состояние (у блока нет полей)
- text/textarea/number/slider/toggle/combo · поля параметров блока · строятся из схемы блока; обязательное поле помечено «*»; текстовые поля автодополняют токены «{переменная}»; secret-поле маскируется; списки/объекты как JSON (плейсхолдеры «Список JSON, например [1, 2]» / «Объект JSON»)

## Редактор · вкладка «Переменные»
- table · «Имя», «Тип», «Область», «По умолчанию», «Хранить» · таблица объявлений переменных
- combo · столбец «Тип» · [опции: строка, целое, дробное, да/нет, список, словарь]
- combo · столбец «Область» · [опции: локальная, профиль, глобальная]
- toggle · столбец «Хранить» · чекбокс-флаг постоянного хранения
- button · «Добавить» · добавить строку переменной
- button · «Удалить» · удалить выбранную строку

Состояния: диагностика — жёлтая подсветка неиспользуемой переменной (тултип «На эту переменную никто не ссылается.»), строка «Не объявлены, но используются: <имена>»; красная подсветка значения по умолчанию с тултипом «Значение не соответствует типу переменной.».

## Редактор · вкладка «Звуки» — секция «Звуки стадий»
- combo · «При запуске» (источник) · [опции: Без звука, Из библиотеки, Синтез речи, Файл]
- combo · «При успехе» (источник) · [опции: Без звука, Из библиотеки, Синтез речи, Файл]
- combo · «При ошибке» (источник) · [опции: Без звука, Из библиотеки, Синтез речи, Файл]
- text · значение источника · плейсхолдеры «Идентификатор звука, например builtin:chime» / «Текст для озвучивания» / «custom:имя-файла.wav» / «Звук не задан»
- button · «Выбрать файл…» · виден только для источника «Файл» [тултип: «Выбрать файл WAV, MP3 или OGG на компьютере.»] (отключается на время импорта — «Идёт импорт звука…»; при недоступности — «Импорт звуков недоступен: не удалось открыть папку звуков профиля.»)
- number · громкость · суффикс « %» [диапазон: 0..100, дефолт 100] [тултип: «Громкость воспроизведения.»]
- toggle · «Ждать окончания» / «Ждать окончания звука» · [тултип: «Команда продолжит следующие действия только после конца звука.»]
- text · длительность · подпись «N.N с» рядом
- button · «Прослушать» · превью (отключена без сервиса превью)
- button · «Стоп» · остановить превью (активна во время проигрывания)

Состояния: статус импорта — «Импортирую…», «Звук «<имя>» добавлен.», русский текст ошибки импорта.
Заметки: каждая из трёх стадий (запуск/успех/ошибка) — отдельная строка с одинаковым набором контролов.

## Редактор · вкладка «История»
- table · «№», «Дата», «Автор», «Правка», «Размер», «Важно» · список версий команды (столбец «Важно» — «★»)
- tree · «Изменение», «Было», «Стало» · структурные отличия выбранной версии от текущей команды (заголовок «Отличия от текущей команды»)
- text · сводка отличий · «Отличий: …» / «Эта версия совпадает с текущей командой.»
- button · «Пометить важной» / «Снять важность» · закрепить версию от очистки
- button · «Откатить…» · откат к версии
- button · «Экспорт…» · экспорт версии в .ayris

Primary actions: «Пометить важной»/«Снять важность», «Откатить…», «Экспорт…» (все неактивны без выбранной версии)
Состояния: экспорт — «Версия N экспортирована в …», «Не удалось экспортировать: …».
Заметки: диалог отката «Откат к версии» («Команда будет заменена содержимым версии N. Текущее состояние сохранится в истории как новая версия.», кнопка «Откатить»).
