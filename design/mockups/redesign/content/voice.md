# Голос (voice)
Иконка: микрофон / звуковая волна
Назначение: Настройка всей речевой цепочки — распознавание речи (STT), синтез речи (TTS), слово активации и микрофон — на одной странице. Страница прокручивается только вертикально.

## Распознавание речи (STT)
- combo · «Режим» · «Онлайн точнее и без моделей на диске, офлайн работает без сети. Авто начинает с облака и откатывается на офлайн при потере связи.» [опции: Только офлайн, Только облако, Авто: облако с откатом на офлайн]
- combo · «Локальный движок» · «Движок распознавания для офлайн-режима. GigaAM точнее на русском.» [опции: GigaAM (локально), Vosk (локально), Whisper.cpp (локально)]
- combo · «Модель» · «Файл модели в папке моделей. Модели скачиваются в менеджере моделей.» [опции: динамический список из каталога для выбранного движка; пункт «<модель> (нет в каталоге)» если модель из конфига отсутствует]
- badge · плашка-предупреждение «Модель для выбранного движка не скачана.» · кнопка закрытия переименована в «Менеджер моделей» [действие: открыть менеджер моделей] [показывается: режим offline/auto и модель не установлена]
- combo · «Облачный провайдер» · «Сервис распознавания для онлайн-режима.» [опции: Яндекс SpeechKit, Google Cloud Speech-to-Text, Azure Speech, OpenAI-совместимый (Whisper)]
- text · «Адрес сервиса» · «Полный URL метода транскрипции OpenAI-совместимого API. Пусто — адрес OpenAI по умолчанию.» [подсказка: https://api.openai.com/v1/audio/transcriptions] [показывается: только для провайдера OpenAI-совместимый]
- text · «Модель» · «Идентификатор модели распознавания у сервиса. Пусто — модель по умолчанию (whisper-1).» [подсказка: whisper-1] [показывается: только для провайдера OpenAI-совместимый]
- text · «Имя записи:» · поле имени записи ключа [подсказка: yandex]
- text · «Ключ облачного сервиса» (маскированное, echo=Password) · «Вставьте ключ — он не попадёт в файл настроек» [заметка: ключ хранится в диспетчере учётных данных Windows, а не в config.toml]
- button · «Сохранить» · сохранить ключ в хранилище Windows [primary]
- button · «Проверить» · проверить состояние записи/введённого значения
- button · «Удалить» · удалить сохранённый ключ [активна только если ключ сохранён]
- badge · плашка-предупреждение «Облачный движок выбран, но ключ не задан — команды будут молча отклоняться.» [показывается: режим online/auto и ключ не задан]
- button · «Записать фразу» · записать короткую фразу для самопроверки [активна после запуска распознавания; результат «Скажите фразу — распознанный текст появится здесь.»]

Primary actions: «Сохранить», «Записать фразу»
Состояния: занятость — индикатор BusyIndicator + «Слушаю…» при записи; успех — ««<текст>»  ·  <мс> мс»; ошибка — «Не удалось распознать: <сообщение>»; статус ключа — «Запись «<ref>»: ключ сохранён/не задан», «Хранилище ключей Windows недоступно.», «Задайте короткое латинское имя записи, например yandex.»
Заметки: карточки «Адрес сервиса» и «Модель» скрыты, пока не выбран провайдер OpenAI-совместимый. Плашка «Изменение применится после перезапуска воркера» + кнопка «Перезапустить» (область STT) внизу секции. Блок «Тест распознавания» описан: «Проверьте микрофон и движок: запишите короткую фразу и сверьте текст.»

## Синтез речи (TTS)
- combo · «Движок» · «Чем озвучивать ответы. Piper — быстрый локальный голос.» [опции: Piper (локально), Silero (локально), Coqui XTTS (локально), Яндекс SpeechKit, Google Cloud TTS, Azure Speech, ElevenLabs, OpenAI-совместимый (OpenRouter…)]
- combo · «Голос» · «Голос выбранного движка. Свои модели можно загрузить ниже.» [опции: динамический список; для облачных движков — редактируемое поле с подсказками (например alloy — или впишите голос сервиса), для openai семена Alloy/Echo/Fable/Onyx/Nova/Shimmer]
- text · «Адрес сервиса» · «Базовый URL OpenAI-совместимого API. Пусто — адрес по умолчанию (OpenRouter).» [подсказка: https://openrouter.ai/api/v1] [показывается: только для движка OpenAI-совместимый]
- text · «Модель» · «Идентификатор модели синтеза у сервиса — обязателен для облачного голоса.» [подсказка: например, openai/gpt-4o-mini-tts] [показывается: только для движка OpenAI-совместимый]
- text · «Имя записи:» · поле имени записи ключа [подсказка: openai]
- text · «Ключ облачного сервиса» (маскированное) · «Вставьте ключ — он не попадёт в файл настроек» [заметка: ключ хранится в диспетчере учётных данных Windows, а не в config.toml] [показывается: облачный движок или включён запасной облачный голос]
- button · «Сохранить» · сохранить ключ [primary]
- button · «Проверить» · проверить состояние ключа
- button · «Удалить» · удалить сохранённый ключ
- slider · «Скорость» · «1.0× — обычный темп речи.» [диапазон: 50..200 %, дефолт 100]
- slider · «Тон» · «Высота голоса относительно обычной.» [диапазон: 50..200 %, дефолт 100]
- slider · «Громкость» · «Громкость озвучки помощника.» [диапазон: 0..100 %, дефолт 80]
- button · «Прослушать» · «Произнести тестовую фразу выбранным голосом с текущими скоростью, тоном и громкостью.» [primary] [активна после запуска синтеза]
- button · «Выбрать файл модели…» · «Piper — файл .onnx, Coqui — файл .pth. Файл копируется в папку голосов.» [активна только для Piper и Coqui]
- toggle · «Запасной облачный голос» · «Если локальный синтез не справился, озвучить ответ через облако.» [подпись переключателя: «Облачный запасной синтез»]

Primary actions: «Сохранить», «Прослушать»
Состояния: занятость — BusyIndicator при прослушивании; ошибка озвучки — «Не удалось озвучить: <сообщение>»; загрузка модели — «Голос «<имя>» добавлен.», ошибки «Ожидается файл <ext> для выбранного движка.», «Не удалось скопировать файл: <ошибка>»
Заметки: карточки «Адрес сервиса», «Модель» и блок «Ключ облачного сервиса» скрыты, пока не выбран облачный движок / включён запасной голос (endpoint и модель — только для OpenAI-совместимого, ключ — для любого облачного или фолбэка). Диалог выбора файла «Выберите файл модели голоса». Плашка «Изменение применится после перезапуска воркера» + «Перезапустить» (область TTS) внизу секции.

## Слово активации (Wake Word)
- toggle · «Активация голосом» · «Реагировать на «Айрис» и его варианты без нажатия клавиш.» [подпись переключателя: «Реагировать на слово активации»]
- combo · «Движок» · «Чем распознавать слово активации.» [опции: openWakeWord, Porcupine, Vosk KWS]
- combo · «Режим микрофона» · «Всегда слушать, только по клавише или оба способа сразу.» [опции: Всегда слушать, По клавише (Push-to-Talk), И то и другое]
- list · «Варианты слова активации» · «Чем больше вариантов, тем терпимее к произношению; чувствительность выше — чаще ложные срабатывания.» [каждая строка: подпись-фраза + slider «Чувствительность «<фраза>»» (0..100 %) + toggle «Вариант «<фраза>»» + кнопка «Удалить»]
- text · поле новой фразы · «Новый вариант, например «слушай айрис»» [действие: Enter или кнопка добавления]
- button · «Добавить» · добавить новый вариант слова активации [primary]
- slider · «Пауза после срабатывания» · «Не срабатывать повторно в течение этого времени.» [диапазон: 200..10000 мс, дефолт 1500]
- toggle · «Режим теста активации» · рядом подпись «Режим теста»
- button · «Сбросить счётчик» · обнулить счётчики срабатываний и ложных
- button · «Отметить ложное» · увеличить счётчик ложных срабатываний

Primary actions: «Добавить»
Состояния: ошибка добавления — «Слово активации должно быть не короче двух символов.»; статус теста — «Режим теста включён/выключен. Срабатываний: <N>, отмечено ложных: <M>. Последнее: «<фраза>» (<уверенность>%).»
Заметки: блок «Проверка слова активации» — «Включите режим и произносите слово: здесь видно каждое срабатывание и уверенность.» Обновление счётчика только пока вкладка видима. Плашка «Изменение применится после перезапуска воркера» + «Перезапустить» (область WAKE) внизу секции.

## Аудио вход
- combo · «Устройство записи» · «Микрофон для распознавания. «Обновить» перечитывает список после hot-plug.» [опции: Системное по умолчанию + перечисленные микрофоны; пункт «<id> (недоступно)» для отсутствующего устройства]
- button · «Обновить» · «Перечитать список устройств после подключения микрофона»
- slider · «Усиление» · «Программное усиление входного сигнала. 100 % — без изменения.» [диапазон: 10..1000 %, дефолт 100]
- meter · «Уровень сигнала» · «Полоса — текущий уровень, вертикальная черта — порог речи. Обновляется, только пока вкладка открыта.»
- slider · «Порог речи (VAD)» · «Ниже порога сигнал считается тишиной. Черта на шкале выше показывает порог.» [диапазон: 0..100 %, дефолт 50] [подпись слайдера: «Порог речи»]
- combo · «Шумоподавление» · «RNNoise добавляет небольшую задержку, но заметно чище в шумной комнате.» [опции: Выключено, RNNoise (лучшее качество, +~10 мс), Спектральное (лёгкое)]
- button · «Калибровать» · «Измерит шум комнаты и вашу речь, затем предложит усиление, порог и шумоподавление.» [primary] [активна после запуска захвата звука]

Primary actions: «Калибровать»
Состояния: подсказка при недоступном устройстве — «Выбранное устройство сейчас недоступно — подключите его или выберите другое.»; калибровка — «Помолчите 3 секунды, затем произнесите: «айрис открой браузер»…», ошибка «Калибровка не удалась: <сообщение>»
Заметки: диалог подтверждения «Применить рекомендованные значения?» с кнопкой «Применить» после калибровки — записывает усиление, порог, шумоподавление и др. Уровень сигнала (LevelMeter) обновляется только при видимой вкладке. Плашка «Изменение применится после перезапуска воркера» + «Перезапустить» (область AUDIO) внизу секции.
