# Логи / DevTools (devtools)
Иконка: инструменты (devtools)
Назначение: Живое окно в работающий Ayris — журнал, таблица пайплайна, Python-консоль и здоровье воркеров. Без запущенного приложения каждый виджет показывает пустую/инертную форму. Кнопка «Сбросить секцию» скрыта.

## Журнал
- log · «Журнал» · Живой журнал приложения. Значения уже замаскированы — секреты сюда не попадают. Уровень можно менять на лету, не перезапуская Ayris. [цвет по уровню: ERROR/CRITICAL, WARNING, DEBUG, прочее] [формат строки: время · уровень · модуль · [request_id] · сообщение]
- combo · «Уровень:» · фильтр журнала по уровню [опции: все уровни, + LOG_LEVELS]
- combo · «Модуль:» · фильтр по модулю, список известных модулей [опции: все модули, + живые модули] [accessibleName: Фильтр по модулю]
- search · «Поиск по логу» · поиск по сообщению/модулю/request_id
- toggle · «Пауза» · остановить дописывание строк в вид
- toggle · «Автопрокрутка» · держать прокрутку внизу [по умолчанию: включено]
- button · «Скопировать видимое» · копирует видимые строки в буфер
- button · «Очистить» · очистить вид журнала
- combo · «Общий уровень:» · меняет и сохраняет общий уровень логирования на лету [опции: LOG_LEVELS]
- text · «Модуль:» · имя модуля для точечного переопределения уровня [плейсхолдер: напр. ayris.core.pipeline]
- combo · (уровень для модуля) · уровень, который задаётся выбранному модулю [опции: LOG_LEVELS]
- button · «Задать» · применить уровень к введённому модулю
- button · «Сбросить» · снять переопределение с введённого модуля
- text · (статус переопределений) · «Переопределений по модулям нет.» либо «Переопределения: <модуль → уровень>, …»
- button · «Открыть папку логов» · открыть каталог логов в проводнике
- button · «Экспорт лога для баг-репорта…» · собрать zip-архив (диалог выбора папки) [действие: диалог «Куда сохранить архив баг-репорта»]
- button · «Открыть папку архива» · открыть папку собранного архива [по умолчанию отключена, включается после сборки]
- text · (статус экспорта) · «Собираем архив…» → «Архив собран: <имя>\nВнутри: <состав>.\nОтправьте файл разработчику вручную — Ayris ничего никуда не загружает.» либо ошибка «Не удалось собрать архив.»

## Пайплайн
- table · «Пайплайн» · Каждый проход: распознавание → интент → действие → результат, с таймингами. Двойной клик по строке — перейти к её логу. [колонки: Время, request_id, STT raw, Интент, Действие, Результат, мс] [дерево: строка прохода раскрывается в стадии с полосой мс; цвет колонки «Результат» по исходу] [accessibleName: Таблица пайплайна / Проходы пайплайна]
- combo · «Результат:» · фильтр таблицы по исходу [опции: все результаты, успех, ошибка, отменено, таймаут, отклонено, не распознано]
- button · «К логу» · показать выбранный проход в журнале [по умолчанию отключена, включается при выборе строки]
- text · (описание ввода команды) · Ввод команды текстом идёт тем же путём, что голос: опасное действие спросит подтверждение. «Сухой прогон» — разобрать, но не выполнять. [показывается только при devtools.text_input]
- text · (поле команды) · строка ввода команды текстом; Up/Down — история, Enter — выполнить [плейсхолдер: Команда текстом, напр. «который час»]
- toggle · «Сухой прогон» · разобрать команду, но не выполнять
- button · «Выполнить» · прогнать введённую команду через pipeline.run_text [kind: primary]
- button · «Повторить последнюю» · повторить последнюю команду из истории
- text · (статус ввода) · «Разбираю…»/«Выполняю…» → «Результат: <исход>, интент: …, ответ: …, ошибка: …» (с префиксом «Сухой прогон. » в режиме сухого прогона); при недоступности «Пайплайн не запущен — ввод недоступен.»

## Консоль
- text · «Консоль» · Python в контексте приложения. Включается один раз за «Понимаю риски», каждый ввод пишется в аудит. Автозапуска сохранённого нет.
- card · (гейт-предупреждение) · «Консоль выполняет любой код Python в контексте приложения — с полным доступом к настройкам, базе и командам. Ошибка здесь может повредить данные. Автозапуска сохранённых сниппетов нет; каждый ввод пишется в журнал безопасности.» [status: warning, показывается пока не подтверждено]
- button · «Понимаю риски» · разовое согласие, открывает консоль и запоминается в devtools.repl_enabled
- log · «Вывод консоли» · область вывода REPL (эхо ввода `>>>`/`...`, результат, ошибки, автодополнение) [моноширинный, только чтение]
- textarea · «Ввод консоли» · многострочный ввод Python; Enter — выполнить готовый стейтмент, Shift+Enter — перенос, Up/Down — история, Tab — автодополнение, Esc — прервать [моноширинный]
- button · «Выполнить» · выполнить введённый код (в фоновом потоке)
- button · «Прервать» · best-effort прерывание выполняющейся команды [по умолчанию отключена, активна при выполнении]
- button · «Очистить вывод» · очистить область вывода
- (статус выполнения) · строка «— прерывание —» в выводе при запросе прерывания

## Воркеры
- table · «Воркеры» · Каждая подсистема живёт в своём процессе. Перезапуск или пауза во время активной сессии прервёт её — Ayris сначала предупредит. [сетка колонок: Воркер, Тип, Статус, Аптайм, Перезапуски, RAM, Пульс] [accessibleName: Здоровье воркеров] [подсветка: колонка «Перезапуски» красным при ≥3]
- badge · «Статус» · статус воркера (метка WorkerStatus)
- meter · «RAM» · резидентная память процесса воркера (МБ)
- meter · «Пульс» · возраст последнего heartbeat («<n> с назад»)
- button · «Перезапустить» · перезапуск одного воркера [действие: при активной сессии — диалог подтверждения]
- button · «Пауза» · пауза/запуск воркера; меняет подпись на «Запустить», когда воркер не жив [действие: при паузе живого во время сессии — диалог подтверждения]
- text · (пусто) · «Супервизор воркеров не запущен.»

Primary actions: «Выполнить» (ввод команды текстом, primary), «Понимаю риски» (гейт консоли), «Экспорт лога для баг-репорта…», «Перезапустить»/«Пауза» (воркеры)
Состояния: пустой журнал — заполняется из кольцевого буфера при открытии; пайплайн без источника — таблица пустая и статичная; ввод команды недоступен без пайплайна («Пайплайн не запущен — ввод недоступен.»); консоль до согласия — виден только гейт; воркеры без супервизора — «Супервизор воркеров не запущен.»; ошибка экспорта — «Не удалось собрать архив.»
Заметки: секция «Ввод команды текстом» рисуется только при флаге devtools.text_input. Текстовая команда проходит те же гейты подтверждения (задача 40), что и голос. Консоль гейтится один раз «Понимаю риски» (devtools.repl_enabled) и аудитит каждый ввод; выполнение в фоновом потоке, Esc/«Прервать» — best-effort. Перезапуск/пауза воркера при активной сессии открывают ConfirmDialog «Идёт активная сессия» («Сейчас идёт голосовая сессия. Если <перезапустить/приостановить> воркер «<имя>», она будет прервана. Продолжить?», кнопка «Прервать и продолжить», опасное). Пайплайн и воркеры опрашиваются по таймеру только пока видимы. Виджеты audit_view.py и data_inventory.py существуют в кодовой базе, но на этой странице НЕ смонтированы (в devtools.py не используются).
