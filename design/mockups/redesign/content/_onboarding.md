# Мастер первого запуска (_onboarding)
Иконка: ракета/сфера (первый запуск)
Назначение: Модальный мастер (QDialog) настройки Айрис из коробки: лента шагов сверху, область шага в центре, навигация снизу. Ведёт по 7 шагам, сохраняет прогресс в конфиг.

## Каркас мастера (общий для всех шагов)
- tabs · «1. Приветствие › 2. Тема › 3. Режим › 4. Микрофон › 5. Модели › 6. Профиль › 7. Проба» · горизонтальная лента шагов с разделителем «›», текущий шаг подсвечен жирным/акцентом [опции: Приветствие, Тема, Режим, Микрофон, Модели, Профиль, Проба]
- badge · «wizardError» · строка ошибки под областью шага, скрыта по умолчанию, цвет error, перенос слов

Primary actions: «Назад», «Пропустить шаг», «Завершить позже», «Далее» (на последнем шаге текст меняется на «Завершить»)
Состояния: заголовок окна «Первый запуск — Айрис»; минимальный размер 760×580; «Назад» отключена на первом шаге; «Пропустить шаг» скрыта, если шаг непропускаемый; ошибка apply() показывает «Не удалось применить настройки шага. Можно пропустить его и продолжить.»
Заметки: прогресс хранится в general.onboarding_last_step / onboarding_completed; прерванный мастер открывается на том же шаге. «Далее» валидирует и применяет шаг атомарно; «Назад»/«Пропустить»/«Завершить позже» ничего не пишут. Финал гасит show_onboarding, ставит onboarding_completed. При любом закрытии движок активации согласуется с реально установленными моделями (reconcile_wake).

## Шаг 1 — Приветствие
- card · «Айрис» · вордмарк (роль h1) под анимированной сферой (LISTENING)
- text · без label · «Голосовой помощник, который работает на вашем компьютере и говорит по-русски. Сейчас коротко настроим микрофон и загрузим базовые модели — это всё, что нужно для первого запуска.»
- text · без label · «Пока Айрис понимает и отвечает только на русском языке.»

Primary actions: «Далее»
Состояния: сфера анимируется только пока шаг виден
Заметки: шаг непропускаемый (can_skip=False), ничего не пишет в конфиг

## Шаг 2 — Тема (Выберите оформление)
- text · без label · «Тему можно сменить в любой момент в настройках. Результат виден сразу.»
- toggle · «Тёмная (фиолетовая)» · «Оформление по умолчанию: глубокий фиолетовый фон, мягкий контраст.» [действие: живой предпросмотр темы]
- toggle · «Светлая» · «Светлый фон — удобно в ярко освещённой комнате.» [действие: живой предпросмотр темы]
- toggle · «Как в системе» · «Следовать светлой или тёмной теме Windows и переключаться автоматически.» [действие: живой предпросмотр темы]

Primary actions: «Далее»
Состояния: выбор применяется в предпросмотр сразу; при уходе без «Далее» предпросмотр откатывается к сохранённой теме
Заметки: радиогруппа (взаимоисключающие); пишет general.theme только на «Далее»; «dark_purple» выбран, если текущая тема dark_purple или dark

## Шаг 3 — Режим (Как Айрис будет распознавать речь)
- text · без label · «Это можно изменить позже на вкладке «Голос».»
- toggle · «Авто (рекомендуется)» · «Сначала пробует облако, а без сети или ключа переключается на локальные модели. Нужен интернет, а на случай отката — базовые локальные модели.»
- toggle · «Только офлайн» · «Всё распознавание идёт на вашем компьютере, звук не уходит в интернет. Потребуется загрузить локальные модели (около 280 МБ).»
- toggle · «Только онлайн» · «Распознавание в облаке выбранного провайдера: быстро и без крупных загрузок, но аудио уходит в интернет и нужен ключ доступа.»

Primary actions: «Далее»
Заметки: радиогруппа; пишет voice.stt.mode на «Далее»

## Шаг 4 — Микрофон
- text · без label · «Выберите устройство записи и проверьте уровень. Калибровка измерит шум комнаты и вашу речь и подберёт усиление и порог.»
- combo · без label · выбор устройства записи [опции: «Системное по умолчанию», перечень устройств, «<id> (недоступно)» для пропавшего сохранённого]
- text · «device_notice» (роль muted) · «Микрофон не найден. Можно продолжить без него и настроить позже на вкладке «Голос».» / «Калибровка станет доступна после запуска захвата звука.» / пусто
- slider · «Усиление» · единица «%» [диапазон: 10..1000, значение из voice.audio_input.gain × 100]
- meter · без label · LevelMeter — живой уровень микрофона с порогом VAD
- text · без label · «Полоса — текущий уровень. Обновляется, только пока идёт захват звука.»
- button · «Калибровать» · kind=primary [действие: снять шум и фразу в потоке]
- text · «calibrate_status» (роль muted) · статус калибровки

Primary actions: «Калибровать», «Далее»
Состояния: кнопка «Калибровать» отключена, если калибровка недоступна (в мастере всегда недоступна — can_calibrate=False); при старте калибровки статус «Помолчите 3 секунды, затем произнесите: «айрис открой браузер»…»; успех показывает summary отчёта; провал «Калибровка не удалась: <message>»
Заметки: шаг пропускаемый; список устройств пуст → предупреждение о ненайденном микрофоне; на «Далее» пишет voice.audio_input.device и gain; уровень приходит по шине AudioLevelChanged только пока идёт захват

## Шаг 5 — Модели (появляется только при наличии бэкенда каталога)
- text · без label · «Минимальный набор для работы «из коробки» — <размер>. Активация, распознавание речи и голос ответа. Модели языковых моделей (LLM) сюда не входят — базовые команды работают и без них.»
- meter · <имя модели oww-melspectrogram> · строка модели: имя + размер + полоса прогресса + статус [статусы: «Ожидание», «Загрузка…», «Установлено», «Ошибка: <текст>» / «Ошибка загрузки»]
- meter · <имя модели oww-embedding> · строка модели с прогрессом и статусом
- meter · <имя модели oww-airis-ru> · строка модели с прогрессом и статусом
- meter · <имя модели gigaam-v3-ctc> · строка модели с прогрессом и статусом
- meter · <имя модели piper-ru-irina> · строка модели с прогрессом и статусом
- button · «Скачать набор (<размер>)» · kind=primary [действие: запустить фоновую загрузку всех недостающих]
- text · «notice» (роль muted) · сообщение о ходе загрузки

Primary actions: «Скачать набор (<размер>)», «Далее»
Состояния: «Загрузка идёт в фоне — можно продолжить, не дожидаясь конца.» после запуска; при полном наборе кнопка «Набор установлен» (отключена) и notice «Весь набор установлен.»; неопределённый прогресс, когда размер неизвестен; ошибки собираются в notice через «; »
Заметки: минимальный набор — 5 моделей ~280 МБ (oww-melspectrogram, oww-embedding, oww-airis-ru, gigaam-v3-ctc, piper-ru-irina); шаг пропускаемый, загрузка живёт в фоне и продолжается после закрытия; по завершении набора согласуется движок активации (reconcile_wake); события прогресса приходят по шине

## Шаг 6 — Профиль (С чего начать)
- text · без label · «Команды можно добавлять и менять позже на вкладке «Команды».»
- toggle · «Чистый профиль» · без описания
- toggle · «Примеры команд» · без описания (выбран по умолчанию)
- toggle · «Импорт из VoiceAttack (.vap)» · без описания
- button · «Выбрать файл .vap…» · виден только при выборе VoiceAttack [действие: диалог выбора .vap]
- text · «pick_caption» · «Файл не выбран.» / имя выбранного файла (виден только при выборе VoiceAttack)
- list · без label · предпросмотр имён команд, которые добавятся (отключён для взаимодействия)

Primary actions: «Далее»
Состояния: при выборе VoiceAttack без файла валидация «Выберите файл .vap или выберите другой вариант.»; если импортёр недоступен — «Примеры» и «VoiceAttack» отключены, выбран «Чистый профиль»
Заметки: радиогруппа; диалог QFileDialog «Файл VoiceAttack», фильтр «Профили VoiceAttack (*.vap)»; предпросмотр строится без записи; apply импортирует выбранное и логирует число добавленных команд

## Шаг 7 — Проба
- text · без label · «Произнесите фразу вслух после слова активации. Проба засчитается, когда команда действительно сработает.»
- text · «progress» (роль muted) · «Проба <N> из <всего>» / «Готово: <всего> из <всего>»
- text · «phrase» (роль h2) · ««<фраза пробы>»» / «Все пробы пройдены 🎉»
- text · «hint» (роль secondary) · подсказка что произойдёт
- text · «recognised» (роль muted) · «Распознано: <текст>»
- text · «status» · «Слушаю…» / «Скажите фразу вслух.» / «Проверяю…» / «Сработало ✓» / «Не удалось проверить: <exc>»
- button · «Проверить текстом» · виден только если доступен канал submit_text [действие: прогнать фразу текстом через пайплайн]
- button · «Повторить» · [действие: сбросить статус текущей пробы]
- button · «Пропустить пробу» · [действие: перейти к следующей пробе]

Primary actions: «Завершить» (последний шаг), «Проверить текстом», «Повторить», «Пропустить пробу»
Состояния: успех засчитывается по событию IntentMatched; распознанный текст — из TranscriptReady; на финальном экране кнопки проб отключены
Заметки: три пробы (фразы совпадают с голосовыми триггерами примеров): «Айрис, открой браузер» → «Откроется браузер на стартовой странице.»; «Айрис, громкость 50» → «Громкость системы станет 50 %.»; «Айрис, поставь таймер 5 минут» → «Запустится таймер на пять минут.» Шаг пропускаемый, не запирает мастер.
