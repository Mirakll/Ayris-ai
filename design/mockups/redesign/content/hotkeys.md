# Горячие клавиши (hotkeys)
Иконка: клавиатура / сочетание клавиш
Назначение: Настройка системных горячих клавиш ассистента и горячих клавиш команд, разрешение конфликтов и режим работы в играх.

## Панель управления (верхняя полоса)
- badge · «Проблемы: {count}» / «Проблем нет» · счётчик проблемных строк (обе таблицы); при count>0 статус warning
- toggle · «Показывать только конфликты и ошибки» · подпись слева «Только проблемные» · фильтрует обе таблицы, оставляя только строки с проблемой [действие: перестроить]

## Системные горячие клавиши
- table · таблица системных хоткеев · колонки: «Действие», «Сочетание», «Статус», «» (кнопки)
- card · «Push-to-Talk» · «Говорить, пока сочетание зажато.»
- card · «Режим Wake Word» · «Включить или выключить активацию по слову.»
- card · «Оверлей» · «Показать или скрыть плавающий оверлей.»
- card · «Mute микрофона» · «Отключить или включить микрофон.»
- card · «Отмена действия» · «Прервать текущее выполнение и озвучку.»
- badge · колонка «Сочетание» · комбинация в моноширинном виде (label_ru) или «—» если не назначена
- badge · колонка «Статус» · «Зарегистрирована» (success) / «Не назначена» (secondary) / «Не зарегистрирована» (warning) / «Конфликт: <владельцы>» (warning) / текст ошибки регистрации (error)
- button · «Назначить» · открывает диалог захвата; отключается если обработчик не запущен [тултип: «Обработчик горячих клавиш не запущен.»]
- button · «Очистить» · снимает сочетание; активна только когда сочетание задано
- button · «Сброс» · возвращает значение по умолчанию для строки; активна только если значение изменено [тултип: «Вернуть комбинацию по умолчанию для этого хоткея.»]

Primary actions: «Сбросить все системные» (кнопка в заголовке секции)

## Работа в играх
- text · «Перехватывать клавиши драйвером Interception — чтобы хоткеи срабатывали в полноэкранных играх, которые прячут обычные горячие клавиши Windows.»
- toggle · «Работа в играх через Interception» · включает перехват через драйвер Interception [действие: проверка драйвера, при отсутствии — откат]
- button · «Скачать драйвер Interception» (ссылка) · появляется только когда драйвер недоступен; открывает https://github.com/oblitum/Interception/releases в браузере

## Горячие клавиши команд
- table · таблица хоткеев команд · колонки: «Сочетание», «Команда», «Папка», «Статус», «» (кнопки)
- badge · колонка «Сочетание» · комбинация (label_ru) или «—»; при проблеме статус warning
- card · колонка «Команда» · название команды (h3); при require_admin — плашка «🛡 нужны права администратора» [тултип: «Команда запускается с повышением прав. Хоткей не сработает поверх окон с более высокими правами, если Ayris запущен без администратора.»]
- text · колонка «Папка» · путь папки через « / » или «— корень —»
- badge · колонка «Статус» · «Активна» (success) / «Команда выключена» (secondary) / «Не зарегистрирована» (warning) / «Конфликт: <владельцы>» (warning) / текст ошибки регистрации (error)
- button · «Открыть команду» (ссылка) · переключает на вкладку «Команды» и выделяет команду
- button · «Назначить» · открывает диалог захвата; отключается если обработчик не запущен [тултип: «Обработчик горячих клавиш не запущен.»]
- button · «Очистить» · снимает хоткей команды; активна только когда сочетание задано
- text · подсказка внизу · «Хоткеям, помеченным 🛡, нужны права администратора. Если Ayris запущен без прав администратора, такой хоткей не сработает поверх окон с более высокими правами. Постоянное повышение включается в разделе «Основные», параметром «Всегда запускать от администратора».»

## Диалог «Назначение сочетания» (модальный)
- dialog · заголовок окна «Назначение сочетания» · доступное имя «Назначение сочетания клавиш»
- text · «Нажмите сочетание» (h2, заголовок диалога)
- meter · превью зажатых модификаторов · «…» по умолчанию, вида «Ctrl + Alt + …» по мере нажатия (Ctrl, Alt, Shift, Win); «—» если захват недоступен
- text · подсказка · «Модификатор сам по себе не подойдёт — добавьте клавишу. Esc — отмена, Delete — очистить сочетание. Клавиши-переключатели (Caps Lock, Num Lock, Scroll Lock, Pause) назначить нельзя.»
- text · при недоступном захвате подсказка меняется на «Захват сочетания сейчас недоступно: обработчик горячих клавиш не запущен.» (в коде: «Захват сочетания сейчас недоступен: обработчик горячих клавиш не запущен.»)
- button · «Очистить» · доступное имя «Очистить сочетание» · снимает привязку
- button · «Отмена» · закрывает без изменения привязки

Primary actions: «Сбросить все системные»; в строках — «Назначить», «Очистить», «Сброс»; в командах — «Открыть команду», «Назначить», «Очистить»; в диалоге — «Очистить», «Отмена»
Состояния:
- Пусто (команды): «Ни одной команде пока не назначен хоткей.»
- Проблемы: счётчик «Проблемы: {count}» / «Проблем нет»
- Ошибка записи (плашки-нотисы): «Не удалось сохранить сочетание.», «Не удалось сбросить системные горячие клавиши.», «Не удалось назначить сочетание команде.», «Не удалось очистить сочетание команды.», «Не удалось сохранить настройку работы в играх.»
- Предупреждения (нотисы): «Сочетание {combo} уже занято системным хоткеем «{clash}».», «Обработчик горячих клавиш не запущен — назначить сочетание сейчас нельзя.», «Библиотека команд недоступна.», «Системные горячие клавиши уже сброшены к значениям по умолчанию.»
Заметки:
- Диалог подтверждения «Сбросить системные горячие клавиши?» с текстом «Вернутся значения по умолчанию:\n{список изменений}\n\nХоткеи команд не затрагиваются.», кнопка подтверждения «Сбросить» (опасное действие).
- Кнопки секции сброса/dirty базового класса скрыты — страница пишет поля точечными кнопками «Назначить»/«Сброс».
- Нотисы работы в играх (InlineNotice) появляются под тумблером; ссылка «Скачать драйвер Interception» — только когда драйвер не готов.
- Живое применение: изменение системного хоткея переписывает config.toml и перерегистрирует хоткей; хоткей команды переписывает триггер команды и вызывает hot-reload.
- Плашка «🛡 нужны права администратора» показывается в строке команды только при require_admin.
- Захват идёт через живой HotkeyManager; при отсутствии обработчика кнопки «Назначить» отключаются.
