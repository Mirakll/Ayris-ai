# Стекло / Aurora (visionOS)

Настроение: матовое стекло, глубина, живое северное сияние

Референсы:
- Apple visionOS / Liquid Glass — https://developer.apple.com/videos/play/wwdc2025/219/
- macOS Big Sur / glassmorphism (истоки) — https://medium.com/@imrnshk199/translucent-interfaces-how-glassmorphism-is-shaping-modern-ios-design-df43a5358e0c
- Aurora UI (CSS-рецепт градиентов) — https://superdesign.dev/styles/aurora
- Glassmorphism dashboard (значения backdrop-filter) — https://superdesign.dev/styles/glassmorphism/dashboard

## Палитра
Тема: тёмная (основной режим). Стекло рассчитано на тёмный aurora-фон.

Фон (сцена, самый нижний слой):
- Базовый холст `#0B0E1A` (почти чёрно-синий)
- Aurora-пятно 1 (индиго/фиолет) `#6D5AE6`
- Aurora-пятно 2 (бирюза/циан) `#2AC9C0`
- Aurora-пятно 3 (розово-маджента) `#E85AA6`

Поверхности (стекло, поверх фона — задаются как rgba, blur делает остальное):
- Панель/сайдбар `rgba(255,255,255,0.06)` (эквивалент осветления от `#171B2E`)
- Карточка `rgba(255,255,255,0.09)`
- Всплывающий слой/поповер `rgba(255,255,255,0.12)`

Границы:
- Обычная (верхний блик стекла) `rgba(255,255,255,0.18)`
- Приглушённая (разделители) `rgba(255,255,255,0.08)`

Акценты:
- Основной `#7C6CFF` (индиго-фиолет), градиент к `#9D7BFF`
- Вторичный `#37E0D0` (циан)

Статусы:
- success `#4ADE80`
- warning `#FBBF24`
- error `#FB5D75`
- info `#5AB0FF`

Текст:
- Первый уровень (заголовки/значения) `#F4F6FF`
- Второй уровень (тело) `rgba(244,246,255,0.72)`
- Третий уровень (подписи/плейсхолдер) `rgba(244,246,255,0.45)`

## Типографика
Семейства:
- UI: `"Inter", "Segoe UI", "SF Pro Display", system-ui, sans-serif`
- Числа/моно (логи, метрики): `"JetBrains Mono", "Cascadia Code", "Consolas", monospace`

Начертания: 600 (заголовки), 500 (акценты/навигация), 400 (тело).

Кегли:
- h1 28px / weight 600 / line-height 34px / letter-spacing -0.02em
- h2 20px / weight 600 / line-height 26px / letter-spacing -0.01em
- body 14px / weight 400 / line-height 21px
- caption 12px / weight 500 / line-height 16px / letter-spacing 0.01em / часто uppercase для меток секций

## Форма
Радиусы:
- Карточки/панели 20px
- Кнопки/поля/комбобоксы 12px
- Чипы/бейджи 999px (капсула)
- Мелкие иконочные кнопки 10px

Границы: 1px сплошная, цвет `rgba(255,255,255,0.18)`; на активных элементах — 1px `rgba(124,108,255,0.55)`.

Блюр стекла:
```css
backdrop-filter: blur(24px) saturate(160%);
-webkit-backdrop-filter: blur(24px) saturate(160%);
```
(панели 24px, поповеры 32px, лёгкие чипы 12px)

Тени/свечение:
```css
/* карточка-стекло: тень вниз + внутренний верхний блик */
box-shadow: 0 12px 40px rgba(0,0,0,0.45), inset 0 1px 0 rgba(255,255,255,0.22);
/* акцентный/активный элемент: цветное свечение */
box-shadow: 0 6px 24px rgba(124,108,255,0.45), inset 0 1px 0 rgba(255,255,255,0.25);
/* фокус ввода */
box-shadow: 0 0 0 3px rgba(124,108,255,0.28);
```

## Компоненты

Тумблер: капсула 44x26px из стекла. Выкл — трек `rgba(255,255,255,0.10)`, граница `rgba(255,255,255,0.18)`, белёсый кружок диаметром 20px. Вкл — трек заливается градиентом `linear-gradient(135deg,#7C6CFF,#37E0D0)` с внешним свечением `0 0 16px rgba(124,108,255,0.5)`, кружок уезжает вправо; переход 220ms.

Слайдер: тонкий трек 4px `rgba(255,255,255,0.14)`, заполненная часть — акцентный градиент. Ползунок — стеклянный кружок 18px с блюром, границей `rgba(255,255,255,0.4)` и мягкой тенью; при захвате чуть увеличивается (scale 1.15) и даёт свечение.

Комбобокс: стеклянное поле высотой 40px, радиус 12px, фон `rgba(255,255,255,0.09)`, справа рисованный шеврон `#F4F6FF` (не системная стрелка). Раскрытый список — отдельный стеклянный поповер blur(32px), пункты с hover-подсветкой `rgba(124,108,255,0.18)` и радиусом 8px.

Кнопка основная: заливка градиентом `linear-gradient(135deg,#7C6CFF,#9D7BFF)`, текст `#F4F6FF` 500, радиус 12px, свечение `0 6px 24px rgba(124,108,255,0.45)`; hover — ярче и +2px подъём тени. Вторичная: прозрачное стекло `rgba(255,255,255,0.08)`, граница `rgba(255,255,255,0.18)`, текст второго уровня; hover — фон `rgba(255,255,255,0.14)`.

Карточка-настройка: горизонтальный стеклянный блок, слева заголовок (h2/body 500 `#F4F6FF`) и описание (caption/body третьего уровня), справа контрол (тумблер/слайдер/комбо), выровненный по центру по вертикали. Радиус 20px, внутренние отступы 16-20px, верхний внутренний блик.

Элемент боковой навигации: строка с иконкой (20px) и подписью. Обычный — текст второго уровня, прозрачный фон. Активный — стеклянная капсула `rgba(255,255,255,0.10)` с левым акцентным градиент-индикатором (3px), иконка и текст первого уровня, лёгкое свечение `inset 0 1px 0 rgba(255,255,255,0.2)`.

Бейдж/чип-статус: капсула (radius 999px), заливка = цвет статуса на 14% (`rgba(74,222,128,0.14)` и т.п.), текст и точка-индикатор 6px — полным цветом статуса, тонкая граница того же оттенка на 30%.

Поле ввода: стекло `rgba(255,255,255,0.07)`, граница `rgba(255,255,255,0.14)`, радиус 12px, высота 40px, плейсхолдер третьего уровня. Фокус — граница акцентная + свечение `0 0 0 3px rgba(124,108,255,0.28)`.

Вкладки/сегменты: стеклянный контейнер-капсула с фоном `rgba(255,255,255,0.06)`; активный сегмент — вложенная стеклянная «таблетка» `rgba(255,255,255,0.14)` с блюром и тенью, плавно переезжающая (translateX) при переключении.

## Иконки
Стиль: линейные (outline), штрих 1.75px, скруглённые концы и стыки (`stroke-linecap:round; stroke-linejoin:round`), сетка 24x24, цвет наследуется `currentColor`. Активные состояния — тот же контур с акцентным цветом или тонким внутренним градиент-заполнением на 20%.

Инлайн-SVG-шаблон:
```html
<svg viewBox="0 0 24 24" width="20" height="20" fill="none"
     stroke="currentColor" stroke-width="1.75"
     stroke-linecap="round" stroke-linejoin="round">…</svg>
```

Начертания под разделы:
- Общие — шестерёнка (круг + 8 зубцов-рисок)
- Голос — микрофон (капсула + дуга-подставка) или волна из 3-4 вертикальных штрихов разной высоты
- Команды — узлы графа: 2-3 кружка, соединённых линиями (node-tree)
- ИИ — искра/сверкание (четырёхлучевая звезда + маленькая рядом)
- Клавиши — прямоугольная клавиша с засечкой снизу или контур клавиатуры 3x2
- Панель — сфера/круг с орбитой (кружок + эллиптическая дуга вокруг)
- Профили — силуэт головы-плеч в круге
- Обновления — круговая стрелка обновления (дуга со стрелкой)
- Логи — строки-документ (прямоугольник + 3 горизонтальные линии текста)
- Приватность — щит с замочком или замок-дужка

## Фон/сцена главной («сфера»/аватар)
- Холст: `#0B0E1A` + 3 больших radial-gradient пятна (aurora-цвета), сильно размытые, медленно дрейфующие:
```css
background:
  radial-gradient(60% 55% at 20% 25%, rgba(109,90,230,0.55), transparent 60%),
  radial-gradient(55% 50% at 80% 30%, rgba(42,201,192,0.45), transparent 60%),
  radial-gradient(50% 50% at 60% 85%, rgba(232,90,166,0.40), transparent 60%),
  #0B0E1A;
filter: blur(0);  /* пятна уже мягкие, при желании обёртка с blur(40px) */
```
- «Сфера»: центральный круг с `backdrop-filter: blur(30px)`, полупрозрачный радиальный градиент внутри (светлое пятно смещено вверх-влево — имитация преломления), внешнее пульсирующее свечение `0 0 80px rgba(124,108,255,0.55)`. Поверх — тонкое кольцо-орбита `conic-gradient` с малой прозрачностью, медленно вращается.
- Частицы: 15-25 мелких светящихся точек (`box-shadow` glow), едва заметный параллакс/дрейф; при активном слушании — уплотняются к сфере и ускоряются.
- Реакция на голос: масштаб и яркость свечения сферы привязать к уровню громкости (scale 1.0→1.06, glow-alpha 0.4→0.7).

## Движение
- Появление панели/карточки: fade + translateY(8px→0) + лёгкий blur(6px→0), 260ms, `cubic-bezier(0.22,1,0.36,1)`.
- Hover стеклянных элементов: подъём тени и осветление фона, 160ms `ease-out`.
- Переключатель тумблера/сегмента: переезд ползунка/таблетки, 220ms `cubic-bezier(0.34,1.56,0.64,1)` (лёгкий overshoot).
- Aurora-фон и пульс сферы: непрерывный дрейф/дыхание, 8-14s `ease-in-out` alternate (очень медленно, чтобы не отвлекать).

## Анти-шаблон
1. Не ставить стекло на плоский одноцветный фон — блюр обязан размывать живые aurora-пятна, иначе панели выглядят как серые бутстрап-карточки.
2. Не использовать чистый чёрный `#000` и чистый белый `#fff` для текста/фона и не рисовать сплошные непрозрачные границы 1px `#ccc` — всё через полупрозрачности и мягкие блики.
3. Не мельчить: избегать острых углов (radius < 10px на панелях), жёстких теней-дропшэдоу без размытия и системных стрелок/чекбоксов — все контролы кастомные и капсульные.

Резюме: тёмное матовое стекло с блюром 24px поверх дрейфующих aurora-градиентов (индиго-циан-маджента), капсульные контролы, индиго-акцент со свечением и дышащая светящаяся сфера на главной.
