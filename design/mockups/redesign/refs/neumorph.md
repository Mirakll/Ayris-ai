# Неоморфизм / Soft UI
Настроение: мягкий монохром, тактильный пластилин, спокойная глубина

Референсы:
- Neumorphism.io — CSS-генератор двойной тени: https://neumorphism.io
- setproduct — Neumorphism design recipe & guidelines: https://www.setproduct.com/blog/neumorphism-design-guide
- Dribbble — Neumorphism UI tips (soft UI): https://dribbble.com/stories/2020/03/05/neumorphism-ui-tips
- superdesign.dev — Neumorphism CSS Recipe 2026: https://superdesign.dev/styles/neumorphism
- Clay morphism / claymorphism (мягкие «пластилиновые» объёмы): https://hype4.academy/tools/claymorphism-css-generator

Палитра: СВЕТЛАЯ тема (канон soft UI — фон и поверхность одного тона, глубину рисуют тени).
- Фон (canvas): `#E4E9F2`
- Поверхность 1 (карточки, панели): `#E4E9F2` (тот же тон — ключ стиля; отделяется тенями, не заливкой)
- Поверхность 2 (утопленные лунки: треки слайдеров, поля ввода, вдавленные вкладки): `#DCE1EC`
- Поверхность 3 (приподнятый ключевой элемент — активная нав., кнопка): `#E9EEF6`
- Границы: обычно НЕТ (глубину дают тени). Тонкая опц. граница `#CDD5E3` (1px) только на glass/оверлеях.
- Акцент 1 (основной, «Ayris blue»): `#5B7CFA`
- Акцент 2 (мягкий фиолет для градиента сферы/hover): `#8A6CF0`
- Success: `#3DBE8B`  Warning: `#E0A63C`  Error: `#E56A6A`  Info: `#4FA3E3`
- Тень тёмная (низ-право): `#B8C0D0` (в rgba для мягкости `rgba(163,177,198,0.55)`)
- Свет верхний (лево-верх): `#FFFFFF` (в rgba `rgba(255,255,255,0.9)`)
- Текст L1 (заголовки): `#2E3650`
- Текст L2 (body): `#5A6480`
- Текст L3 (caption/подписи, disabled): `#9AA3B8`

Типографика:
- Семейство UI: `"Inter", "Segoe UI", system-ui, sans-serif`
- Семейство числа/моно (логи, ресурсы, граф): `"JetBrains Mono", "Cascadia Code", Consolas, monospace`
- Начертания: 600 (h1/h2, активная навигация), 500 (кнопки, ярлыки контролов), 400 (body/caption)
- h1 — 26px / line-height 1.25 / letter-spacing -0.2px
- h2 — 19px / 1.3 / -0.1px
- body — 14px / 1.55 / 0
- caption — 12px / 1.4 / +0.2px (описания под заголовком настройки, статусы)
- Числа в панели ресурсов/логах — tabular-nums, 13px

Форма:
- Радиусы: карточка/панель 20px; кнопка/комбобокс/поле 14px; тумблер-капсула 999px (pill); чип 999px; мелкие иконочные кнопки 12px.
- Границы: 0 по умолчанию; 1px `#CDD5E3` только для glass-оверлея.
- Тень ВЫПУКЛАЯ (extruded, дефолт для карточек/кнопок):
  `box-shadow: 8px 8px 18px rgba(163,177,198,0.55), -8px -8px 18px rgba(255,255,255,0.9);`
- Тень ВЫПУКЛАЯ мелкая (кнопки, чипы):
  `box-shadow: 5px 5px 12px rgba(163,177,198,0.5), -5px -5px 12px rgba(255,255,255,0.85);`
- Тень ВДАВЛЕННАЯ (pressed/inset — треки, поля, активные вкладки, нажатая кнопка):
  `box-shadow: inset 5px 5px 12px rgba(163,177,198,0.6), inset -5px -5px 12px rgba(255,255,255,0.9);`
- Свечение акцента (активный/hover ключевой элемент):
  `box-shadow: 6px 6px 14px rgba(91,124,250,0.35), -6px -6px 14px rgba(255,255,255,0.85);`
- Blur (только для оверлея сферы/всплывашек, не для карточек): `backdrop-filter: blur(16px) saturate(120%); background: rgba(228,233,242,0.6);`
- Правило света: источник всегда сверху-слева — светлая тень уходит в лево-верх, тёмная в низ-право. Единое направление на ВСЕХ элементах, иначе сцена «ломается».

## Компоненты

Тумблер: капсула 52x30px в тон фона. Выкл — трек ВДАВЛЕННЫЙ (`inset`-тень), кружок 22px выпуклый (мелкая extruded-тень) слева, цвет тона фона. Вкл — трек заливается акцентом `#5B7CFA` (лёгкий градиент к `#8A6CF0`), внутри сохраняется мягкая inset-тень, кружок уезжает вправо и остаётся выпуклым белёсым; переезд 220ms с лёгким overshoot.

Слайдер: трек ВДАВЛЕННЫЙ, высота 8px, поверхность 2, inset-тень; заполненная часть — акцент `#5B7CFA`. Ползунок — круглая выпуклая «таблетка» 22px в тон фона с extruded-тенью (тактильная «кнопка»), при захвате чуть вдавливается (тень слабее, scale 0.96) — ощущение нажатия пальцем.

Комбобокс: выпуклое поле высотой 44px, радиус 14px, тон фона, мелкая extruded-тень. Справа — рисованный шеврон `#5A6480` (не системная стрелка). Раскрытый список — отдельная выпуклая карточка с крупной тенью; пункты плоские, hover — лёгкая inset-лунка под пунктом, активный пункт с акцентным текстом.

Кнопка основная: выпуклая, заливка тоном фона, текст акцента `#5B7CFA` 500 (или белый на акцентной заливке для CTA); при hover — усиление extruded-тени, при нажатии — переход в ВДАВЛЕННОЕ состояние (inset-тень) с scale 0.98. Вторичная: та же форма, но мельче тень и текст L2; disabled — тень почти убрана, текст L3, вид «утоплен в фон».

Карточка-настройка: горизонтальный выпуклый блок в тон фона, extruded-тень, радиус 20px, внутр. отступы 18-22px. Слева заголовок (body 500 `#2E3650`) и описание (caption `#9AA3B8`), справа контрол по центру вертикали. Между карточками — воздух 16px (разделители не нужны, тени сами разграничивают).

Элемент навигации: строка с иконкой 20px и подписью. Обычный — плоский, без тени, текст L2, фон = тон canvas. Активный — ВДАВЛЕННАЯ лунка (inset-тень, поверхность 2) ИЛИ приподнятая выпуклая капсула (поверхность 3) с иконкой/текстом акцентного цвета и тонким левым индикатором `#5B7CFA` 3px; выбрать одну метафору на весь сайдбар (рекомендуется вдавленная — «вот где я сейчас нажал»).

Чип-статус: капсула (radius 999px) в тон фона с очень мягкой выпуклой тенью, слева точка-индикатор 7px полным цветом статуса (success/warning/error/info), текст L2 12px. Без цветной заливки фона — цвет несёт только точка, чтобы держать монохром.

Поле ввода: ВДАВЛЕННОЕ (inset-тень, поверхность 2), радиус 14px, высота 44px, текст L1, плейсхолдер L3. Фокус — inset сохраняется + добавляется тонкое акцентное свечение по краю `0 0 0 3px rgba(91,124,250,0.25)`. Ошибка — тонкая обводка/свечение `#E56A6A`.

Вкладки/сегменты: выпуклый контейнер-капсула в тон фона; активный сегмент — ВДАВЛЕННАЯ лунка (inset-тень) с акцентным текстом, плавно переезжает при переключении. Неактивные — плоские, текст L2. Метафора: «нажатая клавиша утоплена».

## Иконки
Стиль: линейные (outline), штрих 2px, скруглённые концы и стыки (`stroke-linecap:round; stroke-linejoin:round`), сетка 24x24, цвет наследуется `currentColor` (L2 в покое, акцент в активном). Для soft UI иконку можно посадить в маленькую квадратную выпуклую или вдавленную «плитку» 36px радиусом 12px — тактильная кнопка-иконка. Заливок избегаем, объём даёт тень плитки, а не сам глиф.

Инлайн-SVG-шаблон:
```html
<svg viewBox="0 0 24 24" width="20" height="20" fill="none"
     stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">…</svg>
```

Начертания под разделы:
- Общие — шестерёнка (круг + 8 зубцов-рисок)
- Голос — микрофон (капсула + дуга-подставка) или волна из 3-4 вертикальных штрихов разной высоты
- Команды — узлы графа: 2-3 кружка, соединённых линиями (node-tree)
- ИИ — искра/сверкание (четырёхлучевая звезда + маленькая рядом)
- Клавиши — прямоугольная клавиша с засечкой снизу или контур клавиатуры 3x2
- Панель — сфера/круг с орбитой (кружок + эллиптическая дуга вокруг)
- Профили — силуэт головы-плеч в круге
- Обновления — круговая стрелка обновления (дуга со стрелкой)
- Логи — строки-документ (прямоугольник + 3 горизонтальные линии текста)
- Приватность — щит с замочком или замок-дужка

## Фон/сцена главной («сфера»/аватар)
Задача — показать сферу «пластилиновой», а не стеклянной. Три приёма:
- Вдавленная лунка-гнездо: сфера лежит в круглой ВПАДИНЕ на холсте (крупная inset-тень под гнездом), сама сфера — extruded-орб чуть выступает из лунки. Даёт максимально «тактильный» soft-UI-эффект.
```css
/* гнездо */
.socket{ border-radius:50%; background:#E4E9F2;
  box-shadow: inset 12px 12px 30px rgba(163,177,198,0.7),
              inset -12px -12px 30px rgba(255,255,255,0.9); }
/* орб */
.orb{ border-radius:50%;
  background: radial-gradient(circle at 35% 30%, #F2F5FB, #D9E0EC 70%);
  box-shadow: 10px 10px 26px rgba(163,177,198,0.6),
              -10px -10px 26px rgba(255,255,255,0.95); }
```
- Мягкое свечение: при активном слушании орб набирает цветной ореол акцента поверх пластилина — `box-shadow` дополняется `0 0 60px rgba(91,124,250,0.45)`, светлое пятно-блик (radial-gradient сверху-слева) чуть ярче. Не превращать в неон — свечение приглушённое.
- Extruded-орб без лунки (запасной вариант): сфера просто выступает из плоского фона на двойной тени, внутри радиальный градиент `#F2F5FB → #D9E0EC` (свет сверху-слева). Реакция на голос: scale 1.0→1.05 и alpha ореола 0.3→0.6, привязать к уровню громкости.
- Частицы (опц.): 8-14 мелких мягких точек тоном чуть светлее фона с крошечной тенью, едва заметный дрейф; при слушании подтягиваются к орбу. Не переусердствовать — монохром важнее.

## Движение
- Появление карточки/панели: fade + translateY(10px→0), 240ms, `cubic-bezier(0.22,1,0.36,1)`. Без блюра — soft UI статичен и «твёрдый».
- Нажатие любого выпуклого контрола: переход extruded→inset (тень «продавливается») + scale 0.98, 120ms `ease-out`; отпускание — обратно 160ms. Ключевая тактильная анимация стиля.
- Переключатель тумблера/сегмента: переезд кружка/лунки, 220ms `cubic-bezier(0.34,1.56,0.64,1)` (лёгкий overshoot — «щелчок»).
- Дыхание/пульс сферы на главной: медленный scale и alpha ореола, 6-10s `ease-in-out` alternate; в покое — почти незаметно, при слушании ускоряется до 1.2-1.6s.

## Анти-шаблон
1. Не занижать контраст текста: главный порок неоморфизма — серый текст на сером фоне. Текст держать на L1/L2 (`#2E3650`/`#5A6480`), НЕ красить его в тон фона; контролы можно монохромить, читаемость — никогда.
2. Единый источник света и мягкие тени: свет всегда сверху-слева на ВСЕХ элементах; никаких жёстких дроп-шэдоу без размытия и никаких разнонаправленных теней — иначе сцена выглядит грязно и «сломано».
3. Не делать всё одинаково выпуклым: если каждый элемент выступает, глаз теряет иерархию и появляется «пупырчатая» каша. Чередовать выпуклое (действия, карточки) и вдавленное (поля, треки, активные состояния), плюс дозировать акцент — он должен быть редким.

Резюме: светлый монохром одного тона, где глубину рисуют только двойные мягкие тени (выпукло/вдавлено при свете сверху-слева), тактильные капсульные контролы «продавливаются» при нажатии, редкий сине-фиолетовый акцент, а «сфера» лежит пластилиновым орбом во вдавленной лунке с приглушённым свечением.
