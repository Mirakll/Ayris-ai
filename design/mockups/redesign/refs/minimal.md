# Минимализм / Swiss

Настроение: светлый воздух, монохром, дисциплина сетки, спокойствие

Референсы:
- Things 3 (Cultured Code) — светлый монохром, воздух, один синий акцент, тонкие разделители
- Linear — https://linear.app — жёсткая дисциплина одного акцента (#5E6AD2), фокус-кольца, отсутствие второго хромата
- Swiss / International Typographic Style — https://en.wikipedia.org/wiki/International_Typographic_Style — сетка, sans-serif (Helvetica/Akzidenz), flush-left, объективность
- Josef Müller-Brockmann «Grid Systems» — https://www.thegraphicdesignschool.com/design-history/joseph-mueller-brockmann/ — модульная сетка, типографика как главный носитель смысла

## Типографика
Семейство UI: "Inter", "Segoe UI", system-ui, -apple-system, sans-serif
Семейство моно (логи/код/значения): "JetBrains Mono", "Cascadia Code", ui-monospace, monospace
Начертания: 400 (body), 500 (контролы, навигация), 600 (заголовки). Жирнее 600 не использовать.
Кегли:
- h1: 28px / line-height 34px / weight 600 / letter-spacing -0.02em
- h2: 20px / 26px / 600 / -0.01em
- body: 14px / 21px / 400 / 0
- caption: 12px / 16px / 400 / +0.01em, цвет Текст 3
Числа/значения — tabular-nums (font-variant-numeric: tabular-nums).

## Форма
Радиусы: контролы 8px, карты 12px, чипы/бейджи 6px, пилюли/тумблер 999px.
Границы: 1px сплошные (Граница слабая внутри карт, Граница чёткая для полей/контролов).
Тени (мягкие, почти незаметные — свет, а не глубина):
- карта: box-shadow: 0 1px 2px rgba(24,24,27,0.04), 0 0 0 1px rgba(24,24,27,0.04);
- всплывающее (dropdown/меню): box-shadow: 0 8px 24px rgba(24,24,27,0.10), 0 0 0 1px rgba(24,24,27,0.06);
- фокус-кольцо: box-shadow: 0 0 0 3px rgba(79,70,229,0.22);
Блюр для оверлеев/стекла: backdrop-filter: blur(12px) saturate(1.1); фон rgba(255,255,255,0.72).
Свечения не использовать (это светлая Swiss-тема).

## Компоненты
Тумблер: пилюля 36×20px, радиус 999px. Выкл — трек #DDDDE0, ручка #FFFFFF 16px с тенью 0 1px 2px rgba(0,0,0,0.15). Вкл — трек #4F46E5, ручка уезжает вправо, переход 160ms. Без подписи внутри.

Слайдер: трек 4px высотой, фон #EAEAEC, заполнение #4F46E5. Ручка — круг 16px #FFFFFF с границей 1px #DDDDE0 и тенью; при захвате появляется фокус-кольцо indigo 22%. Значение — моно tabular справа.

Комбобокс: как поле ввода, высота 36px, фон #FFFFFF, граница 1px #DDDDE0, радиус 8px. Справа шеврон 16px линией (Текст 3). При открытии — меню на Поверхности 1 с тенью dropdown, активный пункт на #EEF0FE с текстом акцента.

Кнопка основная: фон #4F46E5, текст #FFFFFF, weight 500, высота 36px, радиус 8px, паддинг 0 16px. Hover → #4338CA. Без градиента, без тени в покое.
Кнопка вторичная: фон #FFFFFF, текст Текст 1, граница 1px #DDDDE0. Hover → фон #F4F4F5. Ghost-вариант — без границы, текст Текст 2.

Карточка-настройка: строка на Поверхности 1, паддинг 16px 20px, разделитель снизу 1px #EAEAEC (без собственной тени внутри секции). Слева колонка: заголовок 14px/500 Текст 1 + описание 12px Текст 3. Контрол прижат вправо (align-items: center). Между строк — только линия, не карты-в-картах.

Элемент боковой навигации: строка высотой 34px, паддинг 0 12px, радиус 8px, иконка 18px + метка 14px/500. Обычный — текст Текст 2, иконка Текст 3, фон прозрачный. Hover — фон #EFEFF1. Активный — фон #EEF0FE, текст и иконка акцента, слева вертикальная риска 2px indigo (или без — тогда только заливка).

Бейдж/чип-статус: высота 20px, радиус 6px, 11px/500, паддинг 0 8px. Тон = 10% фон + цвет текста статуса: success #16A34A на #E9F6EE, warning #D97706 на #FBF0E1, error #DC2626 на #FBE9E9, info #2563EB на #E7EEFC, нейтральный #52525B на #F4F4F5. Опционально точка 6px слева.

Поле ввода: высота 36px, фон #FFFFFF, граница 1px #DDDDE0, радиус 8px, паддинг 0 12px, текст 14px Текст 1, плейсхолдер Текст 3. Фокус — граница #4F46E5 + фокус-кольцо 22%. Ошибка — граница #DC2626.

Вкладки/сегменты: сегмент-контрол на Поверхности 2 (#F4F4F5), радиус 8px, паддинг 3px. Активный сегмент — «таблетка» #FFFFFF с тенью карты, текст Текст 1/500; неактивный — Текст 2 без фона. Переход подложки 160ms.

## Иконки
Стиль: только линия (outline), штрих 1.5px, stroke-linecap="round", stroke-linejoin="round", без заливки, viewBox 0 0 24 24, currentColor. Размер в UI 18px. Геометрия строгая, минимум деталей (в духе Feather/Lucide). Инлайн: `<svg width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">…</svg>`, цвет наследуется от текста строки.
Примеры под разделы:
- Общие — шестерёнка (settings)
- Голос — микрофон / звуковая волна
- Команды — узлы графа (три круга, соединённые линиями)
- ИИ — искра/sparkle (4-лучевая звезда + малая)
- Клавиши — прямоугольник клавиши со скруглением
- Панель — концентрические круги (сфера/оверлей)
- Профили — контур пользователя (круг + плечи)
- Обновления — стрелка по кругу (refresh)
- Логи — строки текста / терминальный `>_`
- Приватность — щит с галочкой

## Фон/сцена главной («сфера»/аватар)
Светлое стекло, не неон. Сфера — радиальный градиент холодных нейтралей с намёком акцента:
`background: radial-gradient(120px 120px at 38% 32%, #FFFFFF 0%, #EEF0FE 40%, #DADEF7 100%);`
Верхний блик: `::before` — radial-gradient белым 60% → прозрачный, blend-mode: screen.
Мягкое кольцо-обод: `box-shadow: inset 0 0 0 1px rgba(79,70,229,0.15), 0 20px 60px rgba(79,70,229,0.10);` (парение над canvas).
Стеклянная подложка секции: `backdrop-filter: blur(16px) saturate(1.1); background: rgba(255,255,255,0.6); border:1px solid #EAEAEC;`.
Частицы — минимум: 3–5 тонких точек #C7CCF0 с медленным дрейфом; никакого плотного particle-поля. Реакция на голос — лёгкое дыхание масштаба ручки/обода (см. движение), без цветовых вспышек.

## Движение
- Тумблер/сегмент/hover-фон: 160ms cubic-bezier(0.4, 0, 0.2, 1) на transform/background.
- Открытие меню/поповера: 120ms fade + translateY(-4px→0), ease-out.
- «Дыхание» сферы в покое: scale 1→1.03→1, 4s ease-in-out infinite.
- Активация голоса: обод сферы — opacity/box-shadow spread 0→8px, 240ms ease-out, затем спад.
Все переходы уважают prefers-reduced-motion (отключать трансформы, оставлять мгновенную смену).

## Анти-шаблон
1. Не более одного хроматического акцента — всё «цветное», кроме статусов, только indigo; никаких вторых бренд-цветов и градиентных кнопок.
2. Никаких тяжёлых теней/скруглений >12px и карт-в-картах — разделяй строки линией 1px, а не вложенными панелями с тенями (не бутстрап-«коробки»).
3. Типографика ведёт, а не рамки: чёткая иерархия кеглей/веса и flush-left выравнивание вместо центрирования и декоративных бордеров; пустоту (воздух) не заполнять.

Резюме: светлая монохромно-серая Swiss-сетка с единственным indigo-акцентом, тонкими 1px-линиями вместо теней и типографикой Inter во главе — воздух, спокойствие, дисциплина.
