# Editorial Dark / Studio Pro
Настроение: премиальный тёмный, тёплый янтарь, журнальная строгость

Референсы:
- Betterment Design System — midnight canvas, серif-дисплей + GT America, золото #ffc729 точечно: https://www.shadcn.io/design/betterment
- Mercedes-Benz Design System — serif-on-sans раскол, журнальная сетка: https://www.shadcn.io/design/mercedes
- WIRED (nexu-io/open-design) — гигантский serif-хедлайн, hairline-грид, near-black: https://github.com/nexu-io/open-design/blob/main/design-systems/wired/DESIGN.md
- «Black Gold Palette» — золото #D4AF37 держать в 5-15% площади: https://www.media.io/color-palette/black-gold-color-palette.html

## Тема
Только тёмная. Тёплый нейтральный уклон (не синий графит, а угольно-коричневый), золото — редкий акцент на 5-15% площади.

## Типографика
Семейства:
- Display/serif: `"Playfair Display", "PT Serif", Georgia, "Times New Roman", serif` — только h1/h2 и крупные числа.
- UI/sans: `"Inter", "Segoe UI", system-ui, "Helvetica Neue", Arial, sans-serif` — body, контролы, навигация.
- Mono (логи/значения/код): `"JetBrains Mono", "Cascadia Code", Consolas, monospace`.

Кегли / начертания:
- h1: 34px serif, weight 600, line-height 1.15, letter-spacing -0.01em
- h2: 24px serif, weight 600, line-height 1.2
- h3 (заголовок карты): 15px sans, weight 600, line-height 1.3, letter-spacing 0
- body: 14px sans, weight 400, line-height 1.55
- caption: 12px sans, weight 500, line-height 1.4, letter-spacing 0.02em
- overline/раздел: 11px sans, weight 600, uppercase, letter-spacing 0.14em, цвет L3
- mono/значение: 13px, tabular-nums

## Форма
Радиусы: карта/панель 14px, поле ввода/кнопка/комбобокс 10px, чип/бейдж 999px (пилюля), трек слайдера 999px.
Границы: hairline 1px `#332E22`; фокус 1px `#E0A73E` + внешнее свечение.
Тени/свечения (готовые):
- Карта: `box-shadow: 0 1px 0 rgba(255,255,255,0.02) inset, 0 8px 24px rgba(0,0,0,0.45);`
- Поднятая/hover: `box-shadow: 0 12px 36px rgba(0,0,0,0.55);`
- Фокус-glow янтарь: `box-shadow: 0 0 0 3px rgba(224,167,62,0.18);`
- Акцентное свечение (активный тумблер/CTA): `box-shadow: 0 0 18px rgba(224,167,62,0.35);`
- Стекло-панель: `backdrop-filter: blur(18px) saturate(120%); background: rgba(23,21,15,0.72);`

## Компоненты
Тумблер: трек-пилюля 42×22px. Выкл — фон `#282419`, hairline-бордюр, кружок `#877F6C`. Вкл — трек заливается вертикальным градиентом `linear-gradient(180deg,#F2C66B,#E0A73E)`, кружок `#0E0D0B`, добавляется акцентное свечение. Переход 180ms.

Слайдер: трек 4px `#282419`, заполненная часть — градиент янтаря; ручка 16px круг `#F5F1E8` с hairline-кольцом и тенью, на hover вырастает фокус-glow. Активное значение показывается mono-числом справа.

Комбобокс: поле как input (поверхность 2, радиус 10px, hairline), справа рисованный шеврон-SVG L3 (не системная стрелка). Раскрытый список — поверхность 1, hairline, тень карты, выбранный пункт помечен янтарной точкой/левой полоской 2px, hover-строка `#282419`.

Кнопка primary: фон градиент `linear-gradient(180deg,#F2C66B,#E0A73E)`, текст `#0E0D0B` weight 600, радиус 10px, на hover — акцентное свечение и подъём hi-цвета. Кнопка secondary: прозрачный фон, hairline-бордюр `#5A4B22`, текст L1; hover — фон `#1F1C15` и бордюр янтарь.

Карточка-настройка: горизонтальная строка на поверхности 1, слева заголовок (h3 L1) + описание (caption L3) в колонку, справа контрол (тумблер/комбобокс/кнопка), вертикально по центру. Разделители между строками — hairline, без рамки вокруг каждой. Hover всей строки чуть поднимает фон.

Элемент боковой навигации: строка с иконкой 18px + label sans 14px. Обычный — текст L2, иконка L3, прозрачный фон. Активный — фон `#1F1C15`, слева вертикальная янтарная полоска 3px (радиус 2px), иконка и текст L1, иконка окрашена янтарём.

Бейдж/чип-статус: пилюля, 11px uppercase overline. Success/Warning/Error/Info — текст соответствующего цвета на его же заливке `alpha 0.14` с бордюром того же цвета `alpha 0.35`. Пример error: текст `#C25B4E`, фон `rgba(194,91,78,0.14)`.

Поле ввода: поверхность 2, hairline, радиус 10px, паддинг 10×12px, текст L1, placeholder L3. Фокус — бордюр янтарь + фокус-glow. Лейбл сверху overline-стилем.

Вкладки/сегменты: контейнер-пилюля поверхность 2 с внутренним паддингом 3px; активный сегмент — поверхность 3 с hairline и мягкой тенью, текст L1; неактивные — текст L2 без фона. Переход подложки 160ms.

## Иконки
Стиль: только контур (line), stroke-width 1.5px, `stroke-linecap:round`, `stroke-linejoin:round`, без заливки, `stroke: currentColor` (наследует цвет строки навигации). Сетка 24×24, визуальный размер 18px. Углы форм скруглять радиусом ~2px. Активное состояние — тот же контур, `stroke:#E0A73E`.
Инлайн-SVG шаблон: `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">…</svg>`.
Начертания разделов:
- Общие: шестерёнка (круг + 8 зубцов-штрихов).
- Голос: микрофон-капсула + дуга-подставка.
- Команды: узлы графа — 3 кружка, соединённые линиями (нодовый редактор).
- ИИ: искра/звезда из 4 лучей + маленькая рядом (sparkles).
- Клавиши: клавиша-квадрат со скруглением + command-угол.
- Панель: концентрические круги-сфера с орбитой (аватар).
- Профили: контур головы+плеч в круге.
- Обновления: круговая стрелка обновления со стрелкой-наконечником.
- Логи: строки-терминал `>` + горизонтальные штрихи.
- Приватность: замок-дужка + тело со скруглением.

## Фон/сцена главной («сфера»/аватар)
Радиальное тёплое ядро: `radial-gradient(circle at 50% 42%, rgba(242,198,107,0.28), rgba(224,167,62,0.10) 40%, transparent 70%)` поверх canvas.
Сама сфера: круг с `background: radial-gradient(circle at 38% 32%, #F2C66B, #E0A73E 45%, #6E4E17 100%)`, внешнее свечение `box-shadow: 0 0 80px rgba(224,167,62,0.45), 0 0 160px rgba(224,167,62,0.20);`, лёгкий внутренний блик `inset 0 8px 30px rgba(255,255,255,0.15)`.
Дыхание: медленная пульсация масштаба/свечения (см. Движение).
Частицы: 20-40 мелких точек `#F2C66B` alpha 0.3-0.6, медленный дрейф вверх, `mix-blend-mode: screen`.
Атмосфера: тонкая hairline-сетка на фоне (`background-image` из линий `#332E22` шагом 48px, opacity 0.35) — журнальный грид проступает под сценой.
Glass-панель ресурсов/статуса поверх сцены: `backdrop-filter: blur(18px) saturate(120%)`, фон `rgba(23,21,15,0.72)`, hairline.

## Движение
- Дыхание сферы: `transform: scale(1→1.04)` + рост glow, 4s, `ease-in-out`, infinite alternate.
- Появление карт/страницы: fade + `translateY(8px→0)`, 260ms, `cubic-bezier(0.22,1,0.36,1)`, стаггер 40ms между картами.
- Тумблер/сегмент: подложка и цвет 180ms `cubic-bezier(0.4,0,0.2,1)`.
- Hover CTA/строки: фон и glow 160ms `ease-out`; активный аудио — пульс кольца вокруг сферы при распознавании речи.

## Анти-шаблон
1. Золото не заливает крупные поверхности — только акцент в пределах 5-15% (полоска активной навигации, CTA, активный тумблер, значения). Никаких золотых панелей/хедеров.
2. Никаких системных серых стрелок комбобокса, дефолтных синих focus-ring и bootstrap-теней `0 1px 3px rgba(0,0,0,.2)` — только заданные hairline, янтарный фокус-glow и тёплые тени.
3. Serif держать строго для h1/h2 и крупных чисел; весь UI-текст, кнопки и подписи — sans. Не набирать serif-ом body или контролы (это выдаёт «шаблон»).
