# Неон-киберпанк
Настроение: тёмный HUD, неон, ночной город, глитч, синтвейв

Референсы:
- Cyberpunk 2077 — стиль Neomilitarism, сигнальный жёлтый + бирюза/маджента, тонкие рамки и «уголки»: https://www.behance.net/gallery/118663901/Cyberpunk-2077User-Interface-(Part-1)
- Cyberpunk HUD theme (zpwr) «deep-space ink, neon cyan, magenta scanlines»: https://github.com/MenkeTechnologies/zpwr-theme
- Synthwave SaaS Dashboard UI (неон на тёмном, свечение, сетка): https://palette.site/blog/2026-02-16-03-neon-nostalgia-the-synthwave-guide-to-saas-dashboards/
- Cyberpunk color palettes (media.io, hex): https://www.media.io/color-palette/cyberpunk-color-palette.html

## Палитра
Тема: тёмная (единственная — стиль строится на неоне по тёмному, светлой нет).

Фон и поверхности:
- Фон приложения (базовый ink): `#070912`
- Фон-2 / глубокая панель: `#0B0F1E`
- Поверхность (карточка/панель): `#111629`
- Поверхность-2 (поднятая, инспектор, поповер): `#18203A`

Границы:
- Обычная граница: `#243049`
- Активная/hover граница (неон-намёк): `#2FE9FF` при 35% (`rgba(47,233,255,0.35)`)

Акценты:
- Акцент-1 (основной, бирюза/cyan): `#2FE9FF`
- Акцент-2 (магента, вторичный неон): `#FF2FB0`
- Сигнальный жёлтый (в стиле 2077, для «внимание/выделение», не как success): `#FCEE0A`

Семантика:
- Success: `#39FF9E`
- Warning: `#FFB020`
- Error: `#FF3B57`
- Info: `#5AA9FF`

Текст (3 уровня):
- Основной: `#E8F0FF`
- Вторичный: `#9AA7C7`
- Приглушённый / подпись: `#5C6B8F`

## Типографика
Семейства:
- Заголовки/UI: `"Rajdhani", "Chakra Petch", "Segoe UI", "Inter", sans-serif` — узкие, техничные, uppercase-дружелюбные.
- Body/интерфейс: `"Inter", "Segoe UI", system-ui, sans-serif`.
- Моноширинный акцент (значения, теги, код, HUD-метки): `"JetBrains Mono", "Cascadia Code", "Consolas", monospace`.

Начертания: заголовки — 600/700; body — 400/500; моно-метки — 500, часто UPPERCASE.

Кегли:
- h1: 28px / weight 700 / line-height 1.15 / letter-spacing 0.04em / часто UPPERCASE
- h2: 20px / 600 / 1.2 / 0.03em
- body: 14px / 400 / 1.5 / 0
- caption: 12px / 500 / 1.4 / 0.06em (моно, UPPERCASE для HUD-меток)

## Форма
- Радиусы: карточки/панели `10px`, контролы (кнопки, поля, комбобоксы) `6px`, чипы/бейджи `4px` (лёгкая «резкость», не пилюли), крупные секции `14px`.
- Толщина границ: `1px` базовая, `1.5px` для активного/фокуса.
- Тени/свечения (готовые значения):
  - Карточка (глубина): `box-shadow: 0 8px 28px rgba(0,0,0,0.55), inset 0 1px 0 rgba(255,255,255,0.03);`
  - Неон-свечение акцента (фокус/актив): `box-shadow: 0 0 0 1px rgba(47,233,255,0.6), 0 0 16px rgba(47,233,255,0.35);`
  - Магента-свечение (вторичное): `box-shadow: 0 0 14px rgba(255,47,176,0.35);`
  - Текстовое неон-свечение заголовка: `text-shadow: 0 0 8px rgba(47,233,255,0.5);`
- Блюр/glass (панели поверх сцены): `background: rgba(17,22,41,0.6); backdrop-filter: blur(14px) saturate(140%); border: 1px solid rgba(47,233,255,0.14);`

## Компоненты
Тумблер: капсула-трек, но не круглая — радиус `8px`, высота 22px. ВЫКЛ — трек `#18203A` с границей `#243049`, ручка `#5C6B8F`. ВКЛ — трек заливка `#2FE9FF` при 18% с границей `#2FE9FF`, ручка `#2FE9FF` со свечением `0 0 10px rgba(47,233,255,0.6)`; переход ручки 180мс.

Слайдер: тонкий трек 4px, radius 2px, фон `#243049`. Заполненная часть — градиент `linear-gradient(90deg,#2FE9FF,#FF2FB0)`. Ручка — ромб/квадрат 14px повёрнутый 45°, `#0B0F1E` с рамкой `#2FE9FF` и свечением при hover; над ручкой моно-значение в пузыре `#18203A`.

Комбобокс: прямоугольник radius 6px, фон `#111629`, граница `#243049`, справа шеврон-иконка `#9AA7C7`. Hover — граница `#2FE9FF` 35%. Открытый список — поверхность-2 `#18203A` с тонкой неон-рамкой и тенью карточки; активный пункт — левая планка 2px `#2FE9FF` + фон акцент 10%.

Кнопка основная: заливка `#2FE9FF` при 12%, текст `#2FE9FF`, граница `#2FE9FF` 55%, свечение при hover `0 0 16px rgba(47,233,255,0.35)`; можно срезанный угол (clip-path) слева-снизу для «HUD»-вида. Вторичная: прозрачный фон, граница `#243049`, текст `#9AA7C7`, при hover граница/текст → `#E8F0FF`, лёгкое свечение убрано.

Карточка-настройка: горизонтальный ряд — слева заголовок (h2/14px 600 `#E8F0FF`) + описание (caption `#9AA7C7`), справа контрол. Фон `#111629`, radius 10px, граница `#243049`, слева тонкая вертикальная неон-планка 2px `#2FE9FF` при 40% как «маркер строки»; при hover planка ярче + `inset 0 0 0 1px rgba(47,233,255,0.12)`.

Элемент боковой навигации: иконка 20px + подпись (Rajdhani 14px). Обычный — текст `#9AA7C7`, иконка stroke `#5C6B8F`, фон прозрачный. Активный — фон `rgba(47,233,255,0.10)`, левая неон-полоса 3px `#2FE9FF` со свечением, текст `#E8F0FF`, иконка `#2FE9FF`, моно-подпись справа как «код раздела».

Бейдж/чип-статус: моно 12px UPPERCASE, radius 4px, padding 2px 8px, точка-индикатор 6px слева. Success — текст/точка `#39FF9E` на `rgba(57,255,158,0.12)`; аналогично warning/error/info своими hex; граница 1px в цвет при 30%.

Поле ввода: фон `#0B0F1E`, граница `#243049`, radius 6px, текст `#E8F0FF`, плейсхолдер `#5C6B8F`. Фокус — граница `#2FE9FF` 1.5px + свечение `0 0 0 1px rgba(47,233,255,0.5), 0 0 14px rgba(47,233,255,0.25)`; caret `#2FE9FF`. Ошибка — граница/свечение в `#FF3B57`.

Вкладки/сегменты: сегмент-бар на фоне `#0B0F1E`, radius 6px. Активный сегмент — фон `#18203A`, текст `#E8F0FF`, нижняя неон-линия 2px `#2FE9FF` со свечением; неактивные — текст `#9AA7C7`, без фона. Подписи Rajdhani UPPERCASE 12–13px.

## Иконки
Стиль: линейные (outline), stroke `1.75px`, `stroke-linecap="round"`, `stroke-linejoin="round"`, без заливки; вьюбокс `0 0 24 24`. Цвет через `stroke="currentColor"` — обычный `#9AA7C7`/`#5C6B8F`, активный `#2FE9FF`. Для активного состояния допускается `filter: drop-shadow(0 0 4px rgba(47,233,255,0.6))`. Инлайн-SVG: `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round">…</svg>`. Геометрия угловатая, техничная (грани, ромбы, засечки-«теки»), без мягких органик-форм.

Примеры начертаний под разделы:
- Общие: шестерёнка из отрезков (октагон + 6 засечек по граням).
- Голос: волна/осциллограмма — 5 вертикальных штрихов разной высоты в рамке.
- Команды: узловой граф — 3 кружка-нода, соединённые ломаными линиями.
- ИИ: чип/процессор — квадрат с 8 «ножками»-штрихами и точкой-ядром внутри.
- Клавиши: клавиша-клавиатура — прямоугольник со скруглением + 6 точек-кнопок.
- Панель: концентрическая сфера — окружность + 2 орбитальные дуги + центральная точка.
- Профили: контур-персона в шестиугольной рамке (техничный аватар).
- Обновления: круговая стрелка обновления с угловатым наконечником + точка-«прогресс».
- Логи: горизонтальные строки-линии разной длины с ведущей `>`-кареткой.
- Приватность: замок с угловатой дужкой + скважина-ромб.

## Фон/сцена главной («сфера»/аватар)
- Базовая сцена: вертикальный градиент `radial-gradient(120% 90% at 50% 20%, #0B0F1E 0%, #070912 70%)` поверх — синтвейв-сетка: `linear-gradient` перспективные линии `rgba(47,233,255,0.08)` шагом 40px, уходящие к горизонту (mask с fade к верху).
- Сфера: слой 1 — `radial-gradient(circle at 40% 35%, #2FE9FF, #7A2BFF 55%, #FF2FB0 100%)` как ядро; слой 2 — внешнее свечение `box-shadow: 0 0 80px 10px rgba(47,233,255,0.35), 0 0 140px 40px rgba(255,47,176,0.25);`; слой 3 — стеклянный ободок `border: 1px solid rgba(232,240,255,0.15); backdrop-filter: blur(2px);`.
- Частицы/атмосфера: мелкие точки `#2FE9FF`/`#FF2FB0` с `opacity 0.4`, медленный дрейф; лёгкий шум-текстура overlay `opacity 0.04`.
- Сканлайны поверх сцены: `repeating-linear-gradient(180deg, rgba(255,255,255,0.03) 0 1px, transparent 1px 3px)` как `::after`, `pointer-events:none`, `mix-blend-mode: overlay`.
- Пульс речи: свечение сферы усиливается по амплитуде звука (менять blur/opacity внешней тени).

## Движение
- Появление панели/страницы: fade + translateY(8px), 220мс, `cubic-bezier(0.2,0.8,0.2,1)`.
- Неон-пульс сферы/активного индикатора: opacity/box-shadow 1.6с `ease-in-out` infinite alternate.
- Глитч на заголовке/статусе (редко, при событии): 2 clip-path сдвига по X ±2px с cyan/magenta text-shadow, 320мс `steps(2)`, срабатывает разово.
- Hover-свечение контролов: box-shadow/border 140мс `ease-out`.

## Анти-шаблон
- Никаких пилюль-скруглений (border-radius > 12px на контролах) и мягких «material»-теней-размытий серого — только резкие грани + цветное неон-свечение.
- Не использовать чистый белый `#FFFFFF` для текста и чистый серый нейтрал для акцентов: текст — холодный `#E8F0FF`, акценты всегда насыщенный неон на тёмном.
- Не оставлять плоские одноцветные заливки кнопок как в Bootstrap: основной акцент — полупрозрачная заливка + неон-граница/свечение, плюс моноширинные UPPERCASE-метки и HUD-детали (уголки, планки, коды разделов).

Резюме: тёмный HUD ночного города — near-black ink, бирюза+магента неон со свечением и сканлайнами, резкие грани, узкий техно-шрифт и моноширинные UPPERCASE-метки.
