# AiRI Companion

Настроение: уютно, мягко-футуристично, живой компаньон, тёплый минимализм.

Референсы:
- Репозиторий: https://github.com/moeru-ai/airi (self-hosted AI VTuber, Vue 3 + UnoCSS + Reka UI + Three.js/WebGPU, VRM/Live2D на «сцене»)
- Палитра проекта: https://github.com/proj-airi/chromatic (`@proj-airi/unocss-preset-chromatic`, oklch, демо: https://proj-airi-chromatic.netlify.app)
- Компоненты: `@proj-airi/ui` поверх reka-ui; UnoCSS-скилл: https://skillsmp.com/creators/moeru-ai/airi/agents-skills-enforce-rules-for-unocss
- Док: https://moeru-ai-airi.mintlify.app/introduction
- Локально подтверждено в `E:/ыы/airi/resources/app.asar`: ramp `--chromatic-hue/--chromatic-sat/--chromatic-bri/--chromatic-chroma-{50..950}`, primary hue oklch ≈ 25.723 (тёплый коралл), шрифт Inter доминирует, плюс Comfortaa/Quicksand/Nunito/Urbanist/DM Sans; радиусы rounded-lg/xl/2xl/full и 999px; тени `0 8px 32px rgba(0,0,0,.12)` (свет) / `.4` (тьма).

## Типографика
- UI/body: `Inter`, fallback `-apple-system, "Segoe UI", Roboto, sans-serif`.
- Дисплей/заголовки-«уют»: `Quicksand` или `Comfortaa` (округлые), fallback `Nunito, "M PLUS Rounded 1c", sans-serif`. Использовать для h1/логотипа/имени компаньона.
- Моно (код/логи): `DM Mono`, fallback `"Fira Code", Consolas, monospace`.
- Начертания: 400 body, 500 подписи/кнопки, 600 заголовки, 700 h1.
- Кегли: h1 28px / h2 20px / h3 16px / body 14px / caption 12px. Межстрочный 1.5 body, 1.25 заголовки. Заголовки — letter-spacing −0.01em.

## Форма
- Радиусы: карточки/панели `16px` (2xl), контролы/кнопки/поля `12px` (xl), мелкое (чипы/бейджи) `8px`, тумблеры и «pill»-кнопки `999px`. Аватары/иконки в круге `full`.
- Границы: 1px, полупрозрачные (`border` из палитры); на hover — сильная граница + лёгкий подъём тени.
- Тени (soft, тёплые): sm `0 2px 8px rgba(0,0,0,.08)`, md `0 4px 12px rgba(0,0,0,.10)`, lg `0 8px 32px rgba(0,0,0,.12)` (тьма — умножить альфу до .4). Никаких резких чёрных теней.
- Блюр: стекло-панели `backdrop-filter: blur(16px)` + полупрозрачный фон `rgba(255,255,255,.72)` / `rgba(28,26,25,.72)`.

## Компоненты
- Тумблер: pill 999px, трек 40×22px, серый off / коралл on, кружок белый с sm-тенью, translate за 180ms ease-out; фокус — коралловое кольцо 2px с offset.
- Слайдер: трек 4px скруглённый (поверхность-3), заполнение коралл, thumb 16px круг белый с тенью и 1px коралловой границей; при drag — thumb 18px + мягкое halo.
- Комбобокс: поле как input (радиус 12px, 1px граница), справа chevron (не двойная стрелка), popover — карточка 16px с blur, пункты 8px радиус, активный пункт заливка акцент-2, галочка коралл слева.
- Кнопка осн.: заливка коралл, текст белый, радиус 12px, 500, паддинг 10×16, hover темнее + подъём, press без тени. Втор.: прозрачный фон, 1px граница, текст осн., hover — заливка поверхность-2.
- Карточка-настройка: поверхность-1, радиус 16px, 1px граница, паддинг 16-20px; слева title+caption, справа контрол; строки-разделители 1px; hover-строка подсвечивает поверхность-2.
- Элемент навигации: строка с иконкой 20px + подпись, радиус 12px, паддинг 8×12; активный — заливка акцент-2 (тьма: коралл-заливка) + коралловая иконка + левый 3px-маркер опционально.
- Чип-статус: pill 999px, 12px текст 500, паддинг 4×10, мягкая заливка цвета состояния 12-16% + текст того же цвета (success/warning/error/info/коралл для «активно»).
- Поле ввода: радиус 12px, поверхность-1, 1px граница, фокус — коралловая граница + тонкое кольцо, placeholder приглушённый текст; для чата — растущий textarea в стекло-баре внизу сцены.
- Вкладки: сегмент-бар на поверхности-2 радиус 12px, активная вкладка — «pill» поверхность-1 с sm-тенью, скольжение индикатора 200ms; либо подчёркивание 2px коралл для контентных вкладок.

## Иконки
Стиль: Iconify, линейные (outline), штрих 1.5–2px, скругления концов round, единый визуальный вес; заливка только у активного/статусного состояния. Размер 20px в навигации, 16px инлайн.
Наборы: `lucide` / `ph` (Phosphor) как база, `solar` для мягких. Примеры под разделы:

## Фон/сцена главной
Герой экрана — та же абстрактная СФЕРА состояния, что и в остальных вариантах (никакого 3D/Live2D-персонажа сейчас — см. примечание ниже). Оформляем её в тёплом «уютном» ключе AiRI:
- Слои: фон-градиент → мягкое коралловое «пятно света» за сферой → сама сфера → контактная тень/виньетка → UI поверх.
- Фон: тёплый вертикальный градиент `radial-gradient(120% 80% at 50% 20%, #FFF6F0 0%, #FAF9F7 45%, #F1ECE7 100%)` (тьма: `radial-gradient(... #2A211E, #1C1A19, #161413)`).
- Свет за сферой: `radial-gradient(closest-side, rgba(235,132,120,.28), transparent 70%)` — коралловый bloom, `mix-blend: screen`, лёгкая пульсация 6s.
- Сфера: круглый орб с тёплым радиальным градиентом (свет сверху-слева, коралловый подтон), мягкая тёплая тень, тонкий стеклянный ободок; диаметр ~55-65% высоты сцены, по центру. Дыхание scale 1.0↔1.03 период 4-6s; при речи — bloom ярче + короткий bounce.
- Контактная тень/виньетка: под сферой мягкий эллипс `radial-gradient(ellipse 40% 8% at 50% 100%, rgba(0,0,0,.14), transparent)` + едва заметная нижняя виньетка для «приземления».
- Подпись-бабл (реплики): стекло-карточка у сферы, радиус 16px, blur, коралловый хвостик-указатель, имя компаньона 12px коралл сверху, текст 14px; появление — fade+scale 0.96→1 за 200ms, автоскрытие.
- UI-хром: чат-бар и переключатели — плавающие стекло-панели по краям; сцена крупнее и «главнее» контролов.

Возможная БУДУЩАЯ функция (сейчас НЕ реализовывать и нигде не применять): заменить сферу на крупного 3D-VRM/Live2D-компаньона «на сцене» (в Qt — Quick3D-остров). Пока хватает сферы в тёплом ключе.

## Движение
- Дыхание сферы: медленное scale ±1.5% и лёгкое смещение блика, период 4–6s, `ease-in-out`, бесконечно.
- Пульс bloom за сферой: opacity/размер кораллового «пятна света» 6s `ease-in-out` alternate; в покое едва заметно.
- Реакция на речь/событие: короткий bounce сферы (scale 1→1.03→1, 240ms) при новой реплике; bloom ярче на время TTS.
- (Будущее, не сейчас) для 3D-компаньона: auto-blink 3–6s, breathing/sway ±1.5°, look-at за курсором — только когда появится сам аватар.

## Анти-шаблон
1. Никаких чёрных `#000` фонов и резких теней — только тёплый уголь и мягкие полупрозрачные тени; иначе теряется «уют».
2. Сфера — герой экрана: UI не должен визуально перевешивать сцену (плоские дашборд-карточки во всю ширину поверх сферы запрещены). Когда-нибудь на её место встанет 3D-компаньон — сцена должна оставаться «главной» уже сейчас.
3. Один акцент (коралл) + нейтрали: не вводить второй яркий hue (фиолетовый/бирюзовый из код-тем asar — это подсветка синтаксиса, а не бренд); состояния — только приглушённые success/warn/error/info.
