# Ключи облачного распознавания речи

Ayris умеет распознавать речь и без интернета, локальной моделью. Облако нужно
там, где локальная модель ошибается: длинные фразы, редкие слова, диктовка. Эта
страница — про то, где взять ключи для четырёх сервисов и как проверить, что они
работают.

Ключ **не нужно никуда присылать и никуда вставлять руками**. Скрипт
`scripts/check-keys.ps1` спросит его скрытым вводом, положит в диспетчер учётных
данных Windows и сразу проверит одним живым запросом. В `config.toml` попадёт
только имя записи, в логи — только маска вида `••••••••3f9c`.

## Проверка

```powershell
powershell -ExecutionPolicy Bypass -File "E:\мистер бит ест рис\scripts\check-keys.ps1"
```

Первый запуск скачает портативный CPython 3.12 (около 11 МБ, в папку
`_tools\win-python\`) — в систему при этом ничего не ставится, в реестр и в PATH
скрипт не пишет. Дальше он спросит ключи, запишет пять секунд с микрофона и
отправит запись каждому сервису. В выводе будет распознанный текст или текст
ошибки; этот вывод можно целиком показать Claude — ключей в нём нет.

Полезные ключи запуска: `-Providers yandex,openai` — проверить не всех;
`-Wav путь` — взять готовый файл вместо микрофона; `-Force` — ввести ключи
заново поверх сохранённых; `-Reinstall` — пересобрать `_tools\win-python`.

Если микрофон недоступен, скрипт возьмёт тестовую фикстуру из
`tests/fixtures/audio`. Она синтезированная, слов там нет, поэтому проверится
только то, что ключ принят: сервис ответит пустым текстом, и это нормально.

## Где брать ключи

### OpenAI Whisper — самый простой

Личный кабинет на `platform.openai.com`, раздел API keys, кнопка «Create new
secret key». Ключ показывается один раз, начинается с `sk-`. Нужен баланс:
карта привязывается в разделе Billing, минимальный платёж около пяти долларов,
распознавание стоит порядка 0,006 доллара за минуту. Больше ничего указывать не
надо — ни региона, ни каталога. Российские карты не проходят.

### Яндекс SpeechKit — проще всего оплатить из России

В консоли `console.cloud.yandex.ru` нужен платёжный аккаунт (при регистрации
дают пробный грант), затем сервисный аккаунт с ролью `ai.speechkit-stt.user`,
и для него — API-ключ. Кроме ключа скрипт спросит **идентификатор каталога**:
это строка вида `b1g...`, видна в адресной строке консоли и в свойствах
каталога. Каталог не секрет, он хранится в `config.toml` открытым текстом.
Цена — порядка 0,2 рубля за 15 секунд, есть небольшой бесплатный лимит.

### Azure Speech — самый щедрый бесплатный тариф

На `portal.azure.com` создаётся ресурс Speech services. На странице ресурса,
в разделе «Keys and Endpoint», лежат два ключа (годится любой) и регион —
например `westeurope`. Регион скрипт спросит отдельно; это тоже не секрет.
Тариф F0 даёт пять часов распознавания в месяц бесплатно и навсегда, но
требует привязанной карты при регистрации подписки.

### Google Cloud Speech-to-Text — больше всего шагов

На `console.cloud.google.com` создаётся проект, к нему привязывается биллинг,
включается Cloud Speech-to-Text API, и в разделе «APIs & Services → Credentials»
создаётся ключ API. Ключ стоит ограничить: в его настройках выбрать «Restrict
key» и оставить только Cloud Speech-to-Text API. Бесплатно 60 минут в месяц,
дальше около 0,016 доллара за минуту.

## Что дальше

Проверенный ключ приложение возьмёт само: в настройках голоса выбирается режим
распознавания (офлайн, облако или «авто») и провайдер, а ключ читается из
хранилища по имени. В режиме «авто» Ayris идёт в облако, когда есть интернет, и
молча переключается на локальную модель, когда его нет.

Хранилище общее с Windows: ключи видны в «Диспетчере учётных данных» → «Учётные
данные Windows», записи начинаются с `Ayris`. Оттуда же их можно удалить.
