# Задача 44 — Системный трей и автозапуск

**Этап:** G — Интерфейс | **Зависит от:** 43 | **Разделы ТЗ:** 8.3, 8.1

## Цель
Иконка в трее как основная точка управления помощником при закрытом окне: статус цветом, контекстное меню, уведомления, плюс автозапуск с Windows и старт свёрнутым.

## Что сделать
1. `gui/tray.py`: `QSystemTrayIcon` с цветовой индикацией статуса — зелёный (работает), оранжевый (проблема: воркер упал, нет микрофона, нет сети в онлайн-режиме), серый (микрофон выключен / помощник на паузе). Иконки в трёх состояниях под тёмную и светлую панель задач, тултип с текстовым описанием статуса.
2. Контекстное меню: «Вкл/Выкл микрофон» (галочка), «Режим» → Always Listening / Push-to-Talk (радиогруппа), «Оверлей» → Мини / Расширенный / Скрыть (радиогруппа), «Настройки», «Профиль» → подменю со списком профилей и отметкой активного, разделитель, «Выход».
3. Синхронизация в обе стороны: пункты меню публикуют команды в event bus, а состояние пунктов обновляется по событиям из `core/state` (микрофон, режим, режим оверлея, активный профиль). Меню не хранит собственную истину — только отражает состояние; список профилей перечитывается при открытии меню.
4. Уведомления: `notify(title, body, level)` через всплывающие сообщения трея, троттлинг повторов одного типа, уровни info/warning/error с подходящей иконкой. Подключение к событиям, о которых стоит сказать пользователю: краш и перезапуск воркера, потеря микрофона, фоллбек онлайн→офлайн, завершённая загрузка модели.
5. `utils/autostart.py`: автозапуск через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение — путь к текущему исполняемому файлу с флагом `--minimized`. Функции `is_enabled()` (проверка фактического состояния ключа, а не флага в конфиге), `enable()`, `disable()`; расхождение конфига и реестра разрешается в пользу реестра с обновлением конфига. Корректный путь и кавычки для случая запуска из исходников (`python -m ayris`) и собранного `.exe`.
6. Старт минимизированным: флаг командной строки `--minimized` и настройка в конфиге — главное окно не показывается, оверлей поднимается по своим настройкам, трей активен. Двойной клик по иконке трея — открыть окно настроек и вынести его на передний план; повторный клик по уже открытому окну не создаёт второе.

## Осторожно
- Приложение живёт при закрытом окне: `QApplication.setQuitOnLastWindowClosed(False)`, иначе процесс умрёт вместе с окном настроек.
- Ссылку на объект трея держать в приложении, иначе иконка исчезнет после сборки мусора.
- Запись в `HKCU\...\Run` не требует админ-прав, но путь надо брать актуальный — после обновления или переустановки старый путь протухает, проверять и чинить при старте.
- Всплывающие уведомления трея могут быть отключены в системе; не завязывать на них критичный сценарий.

## Готово когда
- [ ] Иконка меняет цвет при смене статуса, тултип объясняет причину оранжевого.
- [ ] Все пункты меню работают и отражают актуальное состояние, включая список профилей.
- [ ] Падение воркера и потеря микрофона показывают уведомление без спама при повторах.
- [ ] Автозапуск включается и выключается, `is_enabled()` соответствует реальному ключу реестра.
- [ ] Запуск с `--minimized` не показывает окно, приложение доступно из трея.
- [ ] Двойной клик по иконке открывает настройки и активирует уже открытое окно.
