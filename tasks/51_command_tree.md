# Задача 51 — Дерево команд

**Этап:** G — Интерфейс | **Зависит от:** 43, 30 | **Разделы ТЗ:** 8.4

## Цель
Левая панель вкладки «Команды»: дерево папок-категорий и команд с drag-and-drop, контекстным меню, поиском и групповыми операциями. Отсюда редактор задачи 52 получает выбранную команду.

## Что сделать
1. `gui/widgets/command_tree.py` — `QTreeView` на кастомной модели поверх репозиториев команд и папок (задача 03): папки как узлы, команды как листья, счётчик команд в подписи папки (включая вложенные), сортировка по полю `order`, ленивое обновление ветки вместо полной перестройки модели при изменении одной команды.
2. Drag-and-drop: перемещение команды между папками (смена `folder_id`), переупорядочивание внутри папки и перемещение папок с проверкой, что папку не тащат внутрь себя. Индикатор места вставки, атомарная запись нового порядка в БД, откат визуального перемещения при ошибке записи.
3. Контекстное меню: создать команду, создать папку, дублировать (с суффиксом «— копия» и без дублирования занятых хоткеев), удалить (с подтверждением через `confirm_dialog` задачи 42, для папки — с указанием количества команд внутри), переименовать (инлайн-редактирование), включить/выключить, экспорт в `.ayris`. Часть пунктов работает на множественном выборе.
4. Поиск и фильтр: поле поиска по имени, тегу и тексту голосового триггера; фильтры по статусу (включена/выключена), по тегу и «только с конфликтами». Дерево сжимается до совпавших узлов с сохранением пути до них, подсветка совпавшего фрагмента, пустое состояние из задачи 42 при отсутствии результатов. Фильтрация не блокирует UI на дереве в тысячи узлов.
5. Визуальная индикация: выключенная команда — приглушённый текст и иконка, конфликт триггеров (одна голосовая фраза или комбинация на две команды, данные от задач 37 и 38) — предупреждающая иконка с тултипом, где перечислены конфликтующие команды. Пересчёт индикации по событиям изменения команд, а не по таймеру.
6. Множественный выбор (`ExtendedSelection`) для групповых операций: включить/выключить, удалить, переместить в папку, назначить тег, экспорт выделенного набора одним файлом. Прогресс и итоговый отчёт для операции над многими командами.
7. Импорт/экспорт через `macros/serializer.py` задачи 30: экспорт отдельной команды, папки целиком и выделенного набора в `.ayris`; импорт файла с предпросмотром содержимого, выбором целевой папки и разрешением конфликтов имён (перезаписать / переименовать / пропустить).
8. Тесты на модели дерева без запуска окна: построение дерева из фикстуры, счётчики в папках, перемещение команды и папки с запретом вложения в себя, фильтр по имени/тегу/триггеру/статусу, групповое переключение `enabled`, round-trip экспорт → импорт.

## Осторожно
- Порядок и `folder_id` — состояние в БД, а не в виджете: после перезапуска дерево должно выглядеть точно так же.
- Не дублировать логику `.ayris` в UI: сериализация и валидация только через задачу 30.
- Удаление папки не должно осиротить команды — либо каскад с явным предупреждением, либо перенос в родителя; правило одно и покрыто тестом.
- Все строки меню, подтверждений и тултипов — на русском; размеры и отступы из метрик темы, без пиксельных констант.

## Готово когда
- [ ] Дерево показывает папки с счётчиками и команды, состояние разворота и выбор восстанавливаются после перезапуска.
- [ ] Перемещение команды между папками и переупорядочивание сохраняются в БД; папку нельзя перетащить внутрь себя.
- [ ] Контекстное меню выполняет все пункты, включая дублирование и экспорт, в том числе на множественном выборе.
- [ ] Поиск по имени, тегу и триггеру плюс фильтры по статусу и тегу отрабатывают на дереве в 1000+ команд без заметной задержки.
- [ ] Выключенные команды приглушены, конфликт триггеров помечен иконкой с перечислением конфликтующих команд.
- [ ] Экспорт папки и импорт `.ayris` с разрешением конфликтов работают; тесты, ruff и mypy зелёные.
