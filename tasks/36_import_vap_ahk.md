# Задача 36 — Импорт VoiceAttack и AutoHotkey

**Этап:** E — Макросы | **Зависит от:** 33 | **Разделы ТЗ:** 7.4

## Цель
Перенос существующих профилей пользователей: парсер VoiceAttack `.vap` с маппингом действий на блоки Ayris и базовый парсер AutoHotkey `.ahk`, с предпросмотром и отчётом о неподдерживаемом.

## Что сделать
1. `macros/importers/base.py` — общий контракт: `ImportResult` (список `CommandModel`, папки, переменные, ссылки на звуки, `warnings`, `unsupported`, счётчики «импортировано N из M»), интерфейс `Importer.parse(path) -> ImportResult` и `apply(result, target_folder)`. Импорт никогда не пишет в БД мимо валидатора задачи 30.
2. `macros/importers/voiceattack.py` — парсер `.vap` (XML): профиль и его имя, команды, фразы-триггеры (включая варианты через `;` и `[скобочные]` альтернативы VoiceAttack), действия, переменные, привязанные звуки, состояние команды и её префиксы. Устойчивость к незнакомым узлам XML — пропуск с предупреждением, а не падение.
3. Таблица соответствия действий VoiceAttack → блоки Ayris в отдельном модуле `macros/importers/vap_mapping.py`: нажатия клавиш и текст → `KeyPress`/`KeyDown`/`KeyUp`/`TypeText`, мышь → `MouseClick`/`MouseMove`/`MouseWheel`, запуск программ → `RunApp`/`RunShell`, окна → `FocusWindow`/`WindowState`, пауза → `Wait`, TTS → `Say`, звук → `PlaySound`, переменные и условия → `SetVar`/`If`, вызов команды → `CallCommand`. Всё, чему нет пары, попадает в `unsupported` с указанием команды и типа действия.
4. `macros/importers/autohotkey.py` — базовый парсер `.ahk`: строки хоткеев (`^!v::`) с нормализацией модификаторов в формат Ayris, `Run`, `Send` / `SendInput` / `SendRaw` (разбор `{Enter}`, `{Ctrl down}`, литерального текста), `WinActivate`, `Sleep`, простые присваивания переменных (`var := значение`, `var = значение`). Директивы, функции, `Loop`, GUI-команды и всё непонятое — либо в комментарий блока `RunShell` (с исходной строкой), либо пропуск с предупреждением; выбор поведения — параметр импорта.
5. Предпросмотр до применения: дерево «команда → блоки» с пометками у сгенерированных блоков, список предупреждений и неподдерживаемого, возможность снять галочки с отдельных команд, выбор целевой папки и стратегии для конфликтов имён (переименовать / заменить / пропустить). Применение — одной транзакцией.
6. Отчёт: «импортировано N из M команд», разбивка по причинам пропуска, экспорт отчёта в текстовый файл для разбора пользователем. Итог публикуется в лог и показывается в UI.
7. Тесты на реальных примерах: фикстуры `.vap` (простой профиль, профиль с условиями, переменными и звуками, профиль с незнакомыми узлами) и `.ahk` (набор хоткеев, `Send` с фигурными скобками, непонятная конструкция). Проверять состав блоков, нормализацию хоткеев, содержимое `unsupported` и то, что результат проходит валидатор задачи 30.

## Файлы
`src/ayris/actions/macros/importers/__init__.py`, `importers/base.py`, `importers/voiceattack.py`, `importers/vap_mapping.py`, `importers/autohotkey.py`, `importers/report.py`, `tests/unit/test_import_vap.py`, `tests/unit/test_import_ahk.py`, `tests/fixtures/imports/*.vap`, `tests/fixtures/imports/*.ahk`

## Осторожно
- `.vap` — чужой XML: парсить безопасно (без загрузки внешних сущностей, `defusedxml` либо явное отключение entity resolution), файл может быть большим и битым.
- Не выполнять ничего из импортируемого профиля в процессе разбора; импортированные `RunShell` попадают в команды выключенными, чтобы случайный запуск чужого скрипта был невозможен.
- Хоткеи VoiceAttack и AHK записываются в разных нотациях — нормализация только через утилиту хоткеев (задача 37), без второго парсера комбинаций.
- Звуки из чужого профиля копировать в папку профиля Ayris, иначе ссылки отвалятся; отсутствующий файл — предупреждение, а не ошибка импорта.

## Готово когда
- [ ] Тестовый `.vap` импортируется: команды, фразы-триггеры, хоткеи, действия, переменные и звуки на месте.
- [ ] Неподдерживаемые действия попадают в отчёт с именем команды, импорт при этом не падает.
- [ ] Базовый `.ahk` даёт команды с корректными хоткеями и блоками `TypeText`/`KeyPress`/`RunApp`/`FocusWindow`/`Wait`.
- [ ] Предпросмотр позволяет исключить команды и выбрать поведение при конфликте имён; применение атомарно.
- [ ] Отчёт «импортировано N из M» верен и выгружается в файл.
- [ ] Все импортированные команды проходят валидатор задачи 30; тесты, ruff и mypy зелёные.
