# Задача 02 — Конфигурация и пути

**Этап:** A — Фундамент | **Зависит от:** 01 | **Разделы ТЗ:** 1.3, 1.4, 8.1, 12, 17

## Цель
Типизированная конфигурация в `config.toml` с валидацией, значениями по умолчанию, горячей перезагрузкой и единой точкой определения всех путей приложения.

## Что сделать
1. `core/paths.py`: все пути в одном месте — корень профиля (`%APPDATA%\Ayris\` по умолчанию, настраиваемый), `config.toml`, `ayris.db`, `models/{stt,tts,wake,llm}`, `plugins/`, `logs/`, `sounds/`, `screenshots/`. Поддержка portable-режима (папка рядом с exe). Создание отсутствующих каталогов.
2. `core/config.py` на pydantic-settings: вложенные модели по секциям, соответствующим вкладкам настроек — `general`, `voice.stt`, `voice.tts`, `voice.wake`, `voice.audio_input`, `ai`, `hotkeys`, `overlay`, `plugins`, `privacy`, `performance`, `updates`.
3. Значения по умолчанию для всех полей: язык `ru`, тема `dark_purple`, режим `auto`, автозапуск `false`, телеметрия `false`, VAD-порог, приоритет аудио-процесса, лимит RAM, размеры пулов потоков.
4. Валидаторы диапазонов: скорость TTS 0.5–2.0, чувствительность wake word 0.0–1.0, громкость 0–100, лимит RAM из допустимого набора.
5. Загрузка/сохранение TOML с сохранением комментариев по возможности; при повреждённом файле — бэкап в `config.toml.broken` и старт на дефолтах с записью в лог.
6. Горячая перезагрузка: наблюдатель за файлом, сигнал `config_changed` с diff изменённых полей. Поля, требующие рестарта воркера (аудио-устройство, модели), помечены флагом в схеме и не применяются на живую — вместо этого запрос на перезапуск воркера.
7. Секреты (API-ключи) хранить отдельно от `config.toml` — в Windows Credential Manager через `keyring`, в TOML только имя записи. Ключи никогда не попадают в логи.
8. Тесты: дефолты, валидация границ, круговорот save→load, поведение на битом файле, определение полей «требует рестарта».

## Файлы
`src/ayris/core/paths.py`, `src/ayris/core/config.py`, `src/ayris/core/secrets.py`, `tests/unit/test_config.py`, `tests/unit/test_paths.py`

## Готово когда
- [ ] Первый запуск создаёт `config.toml` со всеми секциями и дефолтами.
- [ ] Правка файла извне применяется без рестарта, кроме помеченных полей.
- [ ] Битый TOML не роняет приложение.
- [ ] API-ключ сохраняется в keyring и не виден в `config.toml` и логах.
- [ ] Portable-режим кладёт профиль рядом с исполняемым файлом.
