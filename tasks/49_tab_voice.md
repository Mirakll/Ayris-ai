# Задача 49 — Вкладка Голос

**Этап:** G — Интерфейс | **Зависит от:** 43, 09, 11, 13 | **Разделы ТЗ:** 8.1 (вкладка 2), 2, 3, 4

## Цель
Единое место настройки речевого тракта: STT, TTS, wake word и аудио-вход — с тестами прямо во вкладке и применением изменений на лету.

## Что сделать
1. Секция «Распознавание речи (STT)»: выбор движка (облачные и локальные из задачи 11), выбор модели для локальных, режим Online / Offline / Auto, поля ключей API для облачных с маскировкой и кнопкой проверки ключа, кнопка перехода к менеджеру моделей (задача 50), блок «Тест распознавания» — запись фразы, показ распознанного текста и времени обработки.
2. Секция «Синтез речи (TTS)»: движок, голос из списка доступных для движка, слайдеры скорости (0.5–2.0), тона и громкости, кнопка «Прослушать» с тестовой фразой на русском, загрузка своей модели (Piper `.onnx`, Coqui `.pth`) через выбор файла с валидацией формата и появлением голоса в списке.
3. Секция «Wake Word»: движок (openWakeWord / Porcupine / Vosk KWS), редактируемый список вариантов слова активации — добавление, удаление, слайдер чувствительности 0.0–1.0 на каждый вариант; debounce после срабатывания (1.5–2 сек, настраиваемо); режим теста — индикация каждого срабатывания с уверенностью и счётчиком ложных за сессию.
4. Секция «Аудио вход»: выбор устройства из списка с обновлением при hot-plug, усиление (gain), индикатор уровня в реальном времени, порог VAD слайдером с визуализацией текущего уровня относительно порога, тумблер RNNoise с показом добавляемой задержки, кнопка «Калибровать» — запуск мастера из задачи 08 с применением рекомендованных значений по подтверждению.
5. Применение и перезапуск: всё, что можно, применяется на лету (громкость, скорость, порог, чувствительность, gain); смена движка, модели или аудио-устройства требует перезагрузки воркера — явный индикатор «Требуется перезапуск», кнопка перезапуска и прогресс загрузки модели, пока воркер поднимается.
6. Доступность и понятность: если движок выбран, но модель не скачана — inline-предупреждение со ссылкой на менеджер моделей; если облачный движок без ключа — предупреждение вместо молчаливой ошибки при первой команде; тесты (распознавание, прослушивание, wake word) отключены, пока движок не готов.

## Осторожно
- Ни один тест во вкладке не должен блокировать UI-поток: запись, распознавание и синтез идут через воркеры с индикатором ожидания и возможностью отмены.
- Индикатор уровня и визуализация VAD работают только при видимой вкладке — иначе аудио-поток крутится зря.
- Ключи API не логировать и не показывать в открытом виде; хранить по правилам конфига, а не в исходном тексте UI.
- Список устройств может поменяться прямо во время настройки — обрабатывать исчезновение выбранного устройства без падения.

## Готово когда
- [ ] Смена движка STT и режима Online/Offline/Auto сохраняется и применяется, при отсутствии модели показывается предупреждение со ссылкой на менеджер моделей.
- [ ] «Прослушать» произносит тестовую фразу выбранным голосом с учётом скорости, тона и громкости.
- [ ] Варианты wake word добавляются и удаляются, чувствительность на каждом сохраняется, тест показывает срабатывания с уверенностью.
- [ ] Индикатор уровня и порог VAD отражают реальный сигнал, «Калибровать» проставляет рекомендованные значения.
- [ ] RNNoise включается и выключается на лету, задержка показана.
- [ ] Изменения, требующие перезапуска воркера, помечены и применяются по кнопке без перезапуска приложения.
