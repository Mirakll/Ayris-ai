# Задача 47 — Оверлей расширенный

**Этап:** G — Интерфейс | **Зависит от:** 46 | **Разделы ТЗ:** 8.2

## Цель
Расширенный режим оверлея: всё из мини плюс лог диалога, управление микрофоном и режимом, активные таймеры и напоминания, быстрый доступ к профилям, настройкам и текстовому вводу.

## Что сделать
1. `gui/overlay/expanded.py`: расширенная панель на том же окне, что и мини (не второе окно) — сверху сохраняется сфера, панель «Ayris» и индикаторы, ниже разворачивается содержимое. Клик по панели «Ayris» переключает режимы в обе стороны.
2. Лог диалога (`gui/overlay/dialog_log.py`): строки «услышано» и «ответ» с разной стилизацией и временем, автопрокрутка к последнему сообщению с отключением автопрокрутки, если пользователь прокрутил вверх, лимит хранимых строк (настраиваемо, по умолчанию ~100) с отбрасыванием старых, копирование строки в буфер по контекстному меню.
3. Управление: кнопка микрофона (вкл/выкл, состояние совпадает с индикатором), переключатель режима Always Listening / Push-to-Talk, быстрое переключение профиля (компактный выпадающий список), кнопка открытия настроек. Все действия — через event bus, состояние приходит обратно событиями, как в трее.
4. Таймеры и напоминания: список активных из задачи 28 с названием, остатком времени и обратным отсчётом, кнопка отмены на каждом, обновление раз в секунду только когда панель видна; пустое состояние из задачи 42, когда активных нет. Панель читает таймеры через интерфейс-поставщик, а не напрямую из репозитория задачи 28: если задача 28 ещё не сделана, подставляется пустой поставщик, панель показывает пустое состояние, а сам оверлей делается целиком. Жёсткой зависимости от 28 здесь нет.
5. Поле текстового ввода команды: отправка по Enter, текст проходит весь пайплайн как голосовая команда, история введённого по стрелкам вверх/вниз. При фокусе в поле окно временно принимает фокус — вернуть `WS_EX_NOACTIVATE`-поведение после потери фокуса или закрытия расширенного режима.
6. Переход мини ↔ расширенный: анимация размера и прозрачности содержимого за время из токенов темы, без прыжка позиции (растём от текущего угла привязки), запоминание размера расширенного режима в конфиге, ограничение по максимальной высоте с прокруткой содержимого.

## Файлы
`src/ayris/gui/overlay/expanded.py`, `dialog_log.py`, `timers_panel.py`, `command_input.py`, `tests/unit/test_dialog_log.py`

## Осторожно
- Расширенный режим — единственное место оверлея, где нужен фокус (текстовое поле). Не оставлять окно «активируемым» после выхода из режима, иначе сломается поведение мини из задачи 46.
- Не хранить весь диалог в памяти: лимит строк жёсткий, история диалога живёт в БД, а не в виджете.
- Обратный отсчёт таймеров не должен крутить таймер, когда панель скрыта.
- Рост панели у нижнего или правого угла экрана не должен уезжать за границы монитора — разворачиваться в сторону экрана.

## Готово когда
- [ ] Клик по панели «Ayris» разворачивает и сворачивает оверлей с плавной анимацией, позиция привязки сохраняется.
- [ ] Лог диалога показывает распознанное и ответ, автопрокрутка отключается при ручной прокрутке, лимит строк соблюдается.
- [ ] Кнопка микрофона, переключатель режима и выбор профиля меняют состояние и синхронны с треем.
- [ ] Активные таймеры видны с обратным отсчётом, отмена работает, при отсутствии — пустое состояние.
- [ ] Текст из поля ввода проходит пайплайн и попадает в лог диалога как обычная команда.
- [ ] После закрытия расширенного режима оверлей снова не перехватывает фокус.
