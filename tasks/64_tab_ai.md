# Задача 64 — Вкладка ИИ / LLM

**Этап:** G/H — Интерфейс и LLM | **Зависит от:** 43, 63 | **Разделы ТЗ:** 8.1 (вкладка 4)

## Цель
Вкладка настроек ИИ: выбор режима, облачные и локальные провайдеры, редакторы промптов, память и тестовое поле для проверки модели.

## Что сделать
1. Выбор режима работы — три взаимоисключающих варианта (только ИИ, гибрид, только заготовленные команды) с коротким пояснением последствий каждого; при выборе «только команды» секции провайдеров сворачиваются как неактуальные.
2. Секция облачных провайдеров: выбор провайдера, поле API-ключа с маскировкой и кнопкой «Проверить» (результат — зелёная галочка или причина отказа), выбор модели из списка, полученного от провайдера, температура и лимит токенов слайдерами с человеческими подписями. Ключ уходит в keyring через задачу 61, в конфиг не пишется.
3. Секция локальных: адрес Ollama / LM Studio с кнопкой «Проверить соединение», список моделей с сервера, каталог рекомендованных моделей с требованиями к памяти, вердиктом по текущему железу и кнопкой загрузки с прогресс-баром и возможностью отмены.
4. `gui/widgets/prompt_editor.py`: редакторы системных промптов чата и NLU — многострочное поле, кнопка «Сбросить к дефолту» с подтверждением, предпросмотр итогового промпта (с подставленным описанием команд и историей) и счётчиком токенов, чтобы было видно, во что упирается контекст.
5. Настройки истории и памяти: длина истории, порог и модель суммаризации, таймаут сессии, кнопка «Очистить историю диалога» с подтверждением.
6. `gui/widgets/llm_test_panel.py`: поле «спросить у модели» — отправка запроса выбранной конфигурацией, показ ответа стримом, времени до первого токена и полного времени, числа токенов и стоимости запроса. Не трогает историю основного диалога.
7. Привязка всей вкладки к конфигу через `SettingsTab` из задачи 43, регистрация полей в поиске настроек, тесты на pytest-qt: сохранение полей, маскировка ключа, поведение кнопок проверки на моках клиентов.

## Файлы
`src/ayris/gui/tabs/ai.py`, `src/ayris/gui/widgets/prompt_editor.py`, `src/ayris/gui/widgets/llm_test_panel.py`, `tests/unit/test_tab_ai.py`

## Осторожно
- Проверка ключа, список моделей и тестовый запрос — сетевые вызовы: только через воркер или `QThread`, UI не замирает, у каждой операции есть отмена.
- Ключ не показывать в открытом виде и не логировать; после сохранения отображать маску, а не значение.
- Загрузка модели весит гигабайты: прогресс, отмена, понятное сообщение при нехватке места.
- Никаких хардкодов цветов и списков моделей — токены темы из задачи 42, модели с сервера и из каталога.

## Готово когда
- [ ] Переключение режима сразу меняет поведение пайплайна, без рестарта приложения.
- [ ] «Проверить» подтверждает рабочий ключ и внятно объясняет отказ на неверном.
- [ ] Кнопка проверки соединения отличает запущенную Ollama от незапущенной, список моделей подтягивается.
- [ ] Сброс промпта возвращает дефолт, предпросмотр показывает итоговый промпт и число токенов.
- [ ] Тестовое поле выводит ответ, время и потраченные токены, UI при этом отзывчив.
- [ ] Тесты pytest-qt зелёные, mypy strict проходит.
