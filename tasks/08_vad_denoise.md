# Задача 08 — VAD, шумоподавление, калибровка

**Этап:** B — Аудио и речь | **Зависит от:** 07 | **Разделы ТЗ:** 8.1, 10.4

## Цель
Детекция речи и подавление шума в аудио-воркере, плюс калибровка порога под конкретный микрофон и помещение.

## Что сделать
1. `audio/vad.py`: обёртка над webrtcvad — режимы агрессивности 0–3, работа по кадрам 10/20/30 мс, настраиваемый порог.
2. Сегментация фразы: логика «начало речи» (N подряд речевых кадров), «конец речи» (M мс тишины, настраиваемо, по умолчанию ~700 мс), максимальная длина фразы (защита от бесконечной записи), минимальная длина (отсечение щелчков). Публикация `SpeechStarted` / `SpeechEnded` с готовым фрагментом (включая pre-roll из кольцевого буфера).
3. `audio/denoise.py`: RNNoise (опциональная зависимость) с graceful-фоллбеком на простой noise gate, если библиотека не установлена. Переключатель в настройках. Замер добавляемой задержки.
4. `audio/calibration.py`: процедура калибровки — записать ~3 сек тишины, посчитать уровень шума, предложить порог VAD и gain; записать тестовую фразу, проверить, что VAD её ловит целиком. Возвращает отчёт для UI (уровень шума, рекомендованные значения, вердикт).
5. Публикация метрик для визуализации в UI: текущий уровень, флаг «речь идёт», отсечка порога.
6. Тесты на заранее подготовленных WAV-фикстурах (тишина, речь, речь в шуме): корректные границы сегментов, отсечение слишком коротких фрагментов, не режет фразу на паузе внутри предложения.

## Файлы
`src/ayris/audio/vad.py`, `src/ayris/audio/denoise.py`, `src/ayris/audio/calibration.py`, `src/ayris/audio/segmenter.py`, `tests/unit/test_vad.py`, `tests/fixtures/audio/*.wav`

## Готово когда
- [ ] Фраза «айрис открой браузер» отдаётся одним сегментом с pre-roll, без обрезки начала.
- [ ] Пауза внутри предложения (< порога) не разрывает фразу.
- [ ] RNNoise включается/выключается на лету, без него всё работает.
- [ ] Калибровка выдаёт осмысленные значения порога и gain.
- [ ] Тесты на фикстурах зелёные.
