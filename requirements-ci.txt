# Минимальный набор для CI и для прогона тестов в песочнице.
#
# Зачем отдельный файл, а не `pip install -e .[dev]`:
# полный список зависимостей из pyproject.toml тянет движки речи (vosk,
# faster-whisper, piper, openwakeword) и WinAPI-обёртки. Часть из них не имеет
# колёс под нужную платформу или требует системных библиотек, из-за чего
# установка падает на ровном месте и CI краснеет не по делу. Поэтому здесь
# лежит только то, без чего не импортируется уже написанный код.
#
# ПРАВИЛО: версии обязаны совпадать с pyproject.toml. За этим следит тест
# tests/unit/test_packaging.py — если поднял версию в одном месте и забыл в
# другом, тест упадёт с указанием пакета.
#
# По мере закрытия задач сюда добавляются движки: задача 09 — openwakeword,
# 10 — vosk и faster-whisper. Тесты, которым нужно реальное устройство,
# помечаются маркером hardware и в CI не запускаются.
#
# piper-tts (задача 12) сюда НЕ добавлен намеренно: он тянет piper-phonemize, у
# которого нет колёс под python 3.11/3.12 на windows-раннерах, и установка
# падает на сборке из исходников. Тесты это не ломает — `piper`, `torch` и `TTS`
# импортируются внутри методов движков, а не на уровне модуля, поэтому сбор
# тестов их не трогает. Проверка настоящего .onnx помечена маркером hardware.
#
# pyrnnoise, наоборот, в CI нужен: без него класс TestRnnoise целиком уходил в
# skip на всех трёх раннерах — то есть настоящий путь шумоподавления не
# проверялся в CI никогда, и первый же прогон с живой библиотекой в песочнице
# нашёл в нём баг. Но лежит он не здесь, а в requirements-ci-nodeps.txt: из него
# берётся только собранная библиотека, а зависимости его питоньей обёртки
# (matplotlib, audiolab, av) — это лишние сотня мегабайт на каждом раннере и
# лишний риск для пина numpy.
